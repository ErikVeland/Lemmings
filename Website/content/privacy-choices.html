Counts and public records

  1. Open Settings > Privacy.
  2. Change Share counts and records.
  3. Review each player’s separate record-sharing choice in the community ranking controls.

An explicit player choice can remain active independently of the general sharing setting. Check both when you want to stop future public submissions.

Remove shared records

Use Remove shared records for the relevant player. This requests removal of hosted records and action replays while keeping local records.

If the service cannot be reached, the app keeps the request pending and retries it. Turning sharing off alone does not remove earlier submissions.

Local play counts

On Mac, open Settings > Privacy and choose Clear this Mac’s counts. Confirm with Clear counts.

On iPhone, iPad or Apple TV, open Settings > Privacy > Play Insights. Choose Clear local counts, then confirm.

This resets the displayed counts. Earlier counts can remain in a local recovery backup.

You can clear local play counts without changing saved games. This does not reset public aggregate totals, which have no automatic expiry.

The service removes daily aggregate rows older than 90 days when it receives an event or serves a summary.

Calendar access

Revoke the app’s calendar access in system settings to stop Desk Clock from reading events. The clock itself does not require calendar access.

Cloud library

Cloud saves are separate from count-sharing consent. Turning off optional sharing does not disable cloud synchronisation.

Keep recovery material private. A working device-link code or sync password can grant access to your library. Codes expire after ten minutes and can be used once.

Removing the app does not remove existing provider copies. Cloud backups retain the three newest successful snapshots, which can include earlier encrypted data.

For a privacy or recovery request, contact support before deleting local data.

Website logs

App sharing controls do not change website server logs. Routine web access logging is disabled. Error and operating-system logs have separate retention limits.

Read Website data for the logging policy.

Access and deletion requests

Email erik@veland.au to ask about access to, correction of or deletion of data.

Describe whether the request concerns shared records, a cloud library or support correspondence. Do not send passwords, recovery keys or device-link codes.

For existing public records, use Remove shared records for the relevant player. Clearing local counts does not remove those records or cloud saves.

If you need help with saved-game or imported-data removal, contact support before deleting files. Keep recovery sources while a save problem remains unresolved.

Family and shared-device choices

Review both general sharing and each player’s record-sharing choice before a child uses public records. Shared initials, scores and eligible replays can be visible to others.
