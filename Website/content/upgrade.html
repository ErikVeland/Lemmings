Ultimate Lemmings experience

If you own a legal copy of compatible original game assets, import your own files to restore supported classic levels, artwork, fonts and audio. The app stays installed as Ultimate Lemmix: the import adds content, not another executable or a purchase.

You must hold a valid licence for the original Lemmings game on at least one platform to download the Game Assets pack. The 253 MB pack includes the campaigns, artwork, sound effects and standard music.

On iPhone and iPad, version 2.4.4 downloads and installs the pack for you. Choose Download game assets in Game Data, or open any game that has no data yet. Select Agree and download to confirm you hold that licence. Ultimate Lemmix then uses the original artwork, music and game names.

On Mac and Apple TV, download the pack here and follow the folder import steps below until 2.4.4 passes review.

Confirm your game licence

Before you import

  • Prepared restoration resources: If your compatible resource collection came in a ZIP, extract it and locate the Resources folder.
  • Original game folder: Use the Home import controls or Game Data. A folder can restore only what it contains. DOS files, for example, do not supply Macintosh interface artwork or missing soundtracks.
  • Community packs: Some need separate styles, objects or music. NeoLemmix and Chronicles format support remains in beta.

Import on your device

Mac, iPhone and iPad

  1. On Home, open Restore original assets for a prepared collection.
  2. Select the extracted Resources folder. On iPhone and iPad, use the Files picker.
  3. Wait for validation, then open an available restored campaign. Mac can also restore compatible resources from an existing preservation application.

Apple TV

  1. Open the import control on Apple TV.
  2. On a second device on the same local network, open the address shown on the TV.
  3. Select the requested files or extracted resource folder. Wait for Apple TV to validate the transfer.

Apple TV transfers files locally. Keep a copy of your sources in case cached files are cleared.

After the import

Use Settings to choose the artwork or soundtrack. The three starter puzzles always keep their Lix artwork. Imported media does not sync with saves, so import your own files separately on each device.

If content is still missing, check Support or see the field guide. Keep the credits and licence notices with your files.
