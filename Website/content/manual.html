Get started

A small crowd has arrived. Their confidence exceeds their planning.

The Store app includes three independent puzzles: First Steps, Float to Safety and Over the Rise. They introduce walking, floating and climbing.

  1. Open Classic from Home.
  2. Select a starter level.
  3. Read the level requirements.
  4. Choose Continue to enter the level.

The starter puzzles use Lix characters and scenery. Other campaigns require imported game data.

Control the crowd

Select a skill from the skill bar, then select the character who should receive it. The remaining count shows how many assignments are available.

Use the pointer on Mac or touch on iPhone and iPad. Controller controls adapt to the device. Use the app’s control help and button-remapping settings for the current bindings.

Pause before a precise assignment. The selected skill and targeting options affect which character the game selects in a crowd.

Classic skills include Climber, Floater, Bomber, Blocker, Builder, Basher, Miner and Digger. Imported games can use different skills and tools.

The release-rate controls change how quickly characters enter where the level rules allow it. Watch the saved count, rescue requirement and remaining time.

Pause, rewind and ask for help

Use Pause to stop play. Use the step controls for small time changes, rewind to revisit recent play, or fast-forward to move through a familiar section.

Rewind history belongs to the current attempt. Do not treat it as an unlimited archive of every earlier run.

Open Level hints to pause and reveal advice one tier at a time. A checked example route applies only to matching level data. Other levels show General coaching.

Hints do not assign skills. Opening moves are examples, and timing or changed terrain can affect the result. The final hint tier does not reveal a complete solution.

Recorded replays and Hot Seat ghosts show earlier play. They do not control the live crowd.

Import game data

For the classic upgrade, see Upgrade to Ultimate Lemmings.

Use the Home import controls or Game Data to add compatible files. Choose Restore original assets for a prepared resource collection.

Mac, iPhone and iPad

  1. Extract a prepared restoration ZIP before selecting its contents.
  2. Open Restore original assets.
  3. Select the extracted Resources folder.
  4. Wait for validation before opening the restored content.

On iPhone and iPad, use the Files picker. Mac can also restore supported resources from an existing preservation application.

Apple TV

  1. Open the import control on Apple TV.
  2. Connect your browser device to the same local network.
  3. Open the address displayed by Apple TV.
  4. Select the requested files or extracted resource folder.
  5. Wait for Apple TV to validate the transfer.

The transfer page sends files locally. It does not upload them to the hosted save or ranking service. Keep your source files for recovery if Apple TV caches are purged.

What an import changes

An import adds resources for the existing application. It does not install another game executable.

A complete resource collection can restore supported artwork, fonts, sound, music and level libraries. A raw game folder supplies only the data it contains.

Find author downloads in the community library. Add the files with the import control. Open Fan for Classic packs or NeoLemmix for NeoLemmix packs. Some packs need separate styles, objects or music. NeoLemmix and Chronicles are in beta.

Keep original credits and licence notices with your files. Importing a collection does not grant permission to redistribute it.

Journeys and collections

Start Journey builds a route from available content. Collections and playlists give you other ways to organise installed levels.

The included library starts small. Import compatible campaigns to expand the levels available to these features.

To resume a saved route, select its player and session. A solo journey and a shared Hot Seat journey keep separate progress.

Hot Seat

Hot Seat lets players take turns on one device. Each attempt has an owner, while the group keeps a shared campaign.

  1. Open the player or Hot Seat controls.
  2. Add at least two players to the roster.
  3. Choose a game and a house rule.
  4. At a handover, let the named player choose Ready.

Every level passes the turn after a clear. At first fail lets a winner continue. The result controls name the player who will act next.

Earlier players’ ghosts can appear during a retry. They are silent guides with separate recorded terrain and cannot change the live level.

Return to solo keeps the shared campaign for later. Use Saved Hot Seats to return to an older shared session.

Saves and sync

Local saves retain progress and compatible attempts. The selected player and session matter when you resume.

Cloud saves synchronise automatically when a connection and usable provider are available. They include library progress, profiles and journey information.

The cloud library does not contain imported game media or mid-level engine checkpoints. Install compatible content on each device separately.

Keep device-link codes and sync passwords private. A working link or password can give another person access to the linked library.

Read Privacy for the data involved, and Support before changing or removing a save that needs recovery.

Artwork and sound

The Store app uses Lix artwork, selected Lix music and project pixel lettering. Original presentation requires the corresponding imported assets.

Choose the artwork and soundtrack in Settings. Starter levels keep their Lix artwork when Original is selected for other campaigns.

Some sequel actions use neutral Lix poses. Native scenery and tools still follow the imported game. These presentation choices do not change the skill rules.

Use Reduce motion, Reduce flashes, Static home screen and UI size to adjust presentation. Apple TV has a deliberate effects budget.

Desk Clock

Desk Clock provides a game-themed clock view. Its optional next-event display needs calendar permission.

Calendar event titles and times remain in the local calendar and display path. You can revoke access in system settings.

Mac and iOS include Desk Clock widget support. Apple TV uses Top Shelf scenery. Extension behaviour still depends on the platform and installed artwork.
