Make the presentation work for you

Settings include UI size, Static home screen, Reduce motion and Reduce flashes.

Music and effects have separate controls. Pause and step controls let you inspect a level before the next action.

Hints reveal advice in stages. They pause the game and distinguish checked example routes from general coaching.

Input and control names

The app provides pointer, touch and controller paths suited to each platform. Button-remapping options are available in Settings.

Native controls and game interfaces include accessibility names for actions and states. These labels do not establish complete screen-reader coverage.

Current limits

The interface uses pixel lettering and visual playfields. We have not established complete VoiceOver or Switch Control acceptance for this candidate.

The game gallery includes full-size frames so you can inspect the controls and lettering. The Desk Clock film has manual playback controls and a written description.

This page does not claim a completed accessibility conformance audit.

Report a barrier

Contact support with the device, app build, assistive technology and action that caused difficulty. Include the control name if available.
