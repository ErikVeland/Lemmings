## Maintenance

This Mac update simplifies the build tools, removes redundant project files
and keeps earlier release notes available through Git history.

Shared mobile and Apple TV code builds actor lists with fewer temporary
allocations. The shared HUD keeps controls clear of narrow screen divisions.
If a navigation rail leaves too little room for the skill row and Nuke,
the HUD uses the standard deck.

## Compatibility

macOS 12.3 or later, on Apple silicon and Intel. Classic and The Tribes are
Complete. Chronicles and NeoLemmix remain Beta.
