# Ultimate Lemmix 2.4.2

Build: 108
Release base: 7dd5340b9cec5bbb945c2f1da05e098d71cf35f5
Platform builds: Mac 108, iPhone/iPad/Duo 108, Apple TV 108

Ultimate Lemmix is a separate release with shared game features.

- Start with three authored puzzles and Lix characters.
- Use the stone controls, pixel lettering and Lemmix logo.
- Keep HD effects, Journey, Hot Seat, saved games, hints, replays and the Desk Clock.
- Import compatible game data or restore assets from your own collection.
- Use the original presentation after restoring its assets.

The Store package contains alternative media and starter levels. The full local
collection is a separate restoration bundle. Import does not grant permission
to redistribute that collection.

Classic and The Tribes retain their established support. Chronicles and
NeoLemmix remain Beta. Device, hosted-service and Store acceptance evidence is
recorded separately in the current submission dossier.
