# Shared About and game-data transfer parity

This source-backed addendum updates the earlier mobile About description in
[Platform feature parity](PlatformFeatureParity.md) and records the integrated
game-data download recovery. Source, packaging, native execution and physical
device acceptance remain separate claims.

## About on mobile and Apple TV

The shared mobile About route uses the same installed heritage, contributor list
and edition-specific version history as Mac. iPhone, iPad, Duo and Apple TV expose
About, Version history and Contributors through the existing bitmap tab strip.
A release opens its own reading page; Back restores the release index.

The heritage includes the Lemmings Forums acknowledgement, with a link on Mac
and iOS and a QR/address page on TV. Mobile retains the Lix artwork and music
licences and the NeoLemmix Introduction Pack attribution.

Bundled credits remain available before the first successful contributor refresh.
Failed requests retain the saved list and offer Retry. Leaving About or hiding
its controller cancels the request, and late completion cannot repaint another
destination. Restoring game assets does not replace installed About documents
or the app's release identity. Both mobile resource paths and the unsigned
source-gate fixture include all three documents.

The Duo static heading and system-region clearance also cover these reading
pages. [Shared About pages](AboutParity.md) records the packaging and isolated
request-test boundaries. Native compilation, rendered states and physical
device acceptance must be recorded separately from those checks.

## Owned game-data downloads

Ultimate Lemmix iPhone and iPad, including Duo, use an OS-managed download after
the existing licence confirmation. The requested transfer permits cellular,
expensive and constrained connections when iOS and the carrier allow them.
The OS can continue transferring while suspended. Reopening Game Data after a
relaunch collects a completed transfer or reattaches to an active one before the
existing size, SHA-256 and archive checks and foreground import.

A missing OS task reports the interruption without silently starting another
full transfer. Mac and TV retain foreground transport; the phone lifecycle does
not change TV's separate local-browser import. A primary timeout tries the
existing alternate mirror once, with distinct waiting, retry and final errors.
An online foreground request that remains at zero bytes offers Try another
server after its sustained wait. Explicit cancellation also cancels a persisted
background task during the initial reattachment handoff.

Cellular access, screen lock, suspension, relaunch and background-daemon timing
remain physical iOS acceptance checks. A controlled test archive can exercise
an idle primary, alternate-server handoff, a trickling response and reconnect
without using a production download or altering the archive integrity rules.

The shared iOS source gate still selects the checkout's product through
`Tools/Publication/ios_source_gate.py`. Its generated, verified starter fixture
is restricted to unsigned source checks. This integration preserves that gate
and the progress, archive-verification and restored-library checks. Signed
release resources and physical device acceptance remain separate.
