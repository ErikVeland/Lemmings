# Shared sessions

Open **Shared Session…** from the app menu, **Shared session** in Player Profiles, or **Players** on a result page. Add profiles in Player Profiles first. Select the people who will take turns. The host stays in the session; guests follow the order in which they join. Number keys 1–8 toggle guests.

The result page offers **Retry as [next player's initials]**. It restarts the same level with its original starting conditions and a new attempt owned by that player. **Retry** keeps the current player. After a failed attempt, Enter passes the turn when a shared session is active. R retries with the current player; N passes the turn. After a clear, Enter still continues to the next level.

Classic campaigns, imported levels, NeoLemmix, Lemmings 2 and Lemmings 3 use the same turn owner. Each completed attempt keeps its own player, records and arcade achievements. Joining or leaving cannot change the owner of a run already in progress.

Campaign progress belongs to the host and stays shared throughout the session. Guest profiles do not inherit the host's campaign saves. The roster lasts until the app closes, the host changes, or **Play solo** is selected. A handoff is unavailable while records have a save error.
