# Ultimate Lemmings — beta 23

Version 0.1, build 23. Universal Mac app for Intel and Apple silicon, macOS 13 or later.

This beta consolidates the Classic interface and targeting fixes for the approach
to 1.0. It does not expand the compatibility claims in Release Scope.md.

## Fonts and graphics

- Original game lettering stays in the menus when changing graphics, selecting
  fan packs, or selecting a release without its own Macintosh artwork.
- Settings, keyboard help, selectors and speed controls use the game’s pixel
  artwork. Focus and selection remain distinct, with keyboard and controller input.
- Results show earned stars without repeating their meaning in explanatory text.
- The frozen-level keyboard guide shows commands over the current playfield.

## Skill targeting

- Green means a nearby lemming can accept the selected skill. Clicking chooses
  the nearest eligible lemming, including in crowds.
- A small movement allowance keeps a visible green target selectable between
  frames. Out-of-range lemmings remain excluded.
- Grey means no eligible target. Successful assignments pulse bright green;
  an already assigned skill gives a brief orange cue. An eligible neighbour
  takes priority. Reduced-flash settings are respected.

## Verified level targets

Rescue targets and the 120 original hint decks now match the shipping engine.
The fresh audit retains every earlier certificate and adds five full-rescue proofs.

## Continuing from beta 22

Shared Hot Seat saves, turn identity, paused handovers, speed controls, seasonal
music selection and interruption recovery remain part of this beta. Existing
profiles and progress use the same save format.

## Release boundary

The original 120-level Lemmings campaign and Xmas 1991 have preserved winning
routes. Other Classic releases, conversions and fan packs remain within the
validation scope, but are not all proven complete. L2 and L3 remain previews.

Physical controller journeys, physical Intel and minimum-macOS testing, full
VoiceOver navigation, sustained performance testing and Game Center failure
recovery remain open before 1.0. See Release Scope.md for the detailed boundary.

The standard archive uses local records. The separate Game Center archive needs
a registered test Mac and uses the development service.

## Please test

1. Switch between Classic, fan packs and both graphics settings; check menu lettering.
2. Assign skills in crowds, while scrolling, paused and at high speed.
3. Retry and advance after wins and failures in a two-player Hot Seat.
4. Open the keyboard guide, change UI size and return through the pause menu.

Report the level, selected skill, graphics setting and input device for any regression.
