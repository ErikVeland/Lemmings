# Ultimate Lemmings 2.0.3 for Macintosh

Build: 86
Release base: v2.0.2

This maintenance release fixes language selection in Settings.

## Language selection

Language buttons now accept clicks across their visible width. Previously,
native radio-button input did not match the centred pixel captions, so clicking
a language could leave System default selected.

Open **Settings > Gameplay > Language**. Select a language to preview it.
Choose **Apply** to save the choice or **Back** to restore the previous language.
System default continues to follow the device language. Keyboard navigation,
accessibility roles and the original pixel artwork are retained.
Reopening What's New also uses the selected language immediately.

## Compatibility and known limits

The public app targets Apple silicon and Intel Macs running macOS 12.3 or later.
The slim fresh-install download contains essential music and offers optional
soundtrack libraries. Automatic updates retain the full soundtrack.

Classic and The Tribes retain their published Complete classifications.
Chronicles and NeoLemmix remain Beta. This update does not change engine rules,
level content or the existing campaign and source-fidelity limits.

The eight translated language packs remain AI-assisted drafts. Human language
review, physical controllers, VoiceOver, audible listening, minimum-OS and Intel
hardware, HDR appearance and live cross-device synchronisation retain their
recorded validation gaps. Mobile and TV releases have separate gates.
