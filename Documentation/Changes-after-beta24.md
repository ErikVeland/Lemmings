# Changes after beta 24

- Holding F ramps through the speed tiers. Releasing F keeps the reached tier, including 2×, 3×, 5× and 10×. A quick tap returns to normal speed.
- Clicking a speed arrow applies the selected tier immediately, including from 1×. Keyboard speed arrows use the same behaviour.
- Shift and held mouse/controller boosts retain their temporary behaviour. Emergency exits, focus loss and new-level resets still stop or clear held input.
- Keyboard help and the frozen-level guide explain the retained F speed.

These changes ship in beta 25. The beta 24 release ZIP is unchanged.
