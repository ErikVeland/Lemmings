# Ultimate Lemmings 1.7.1 — Fixes

Build: 54
Release base: v1.7.0

## Oh My! All Lemmings!

- Solo and Hot Seat journey sessions start again. In 1.7.0, macOS could open the
  app from a temporary location, and then every campaign level looked changed.
- The journey has updated lesson order and more verified solutions.
- A saved run or playlist that uses a bundled campaign now opens after an update.
  Before, the game could mark these levels as changed.
- If a session cannot start, the message names the level and pack that stopped it.

## Fixes

- NeoLemmix lemmings are no longer drawn upside down.
- Bundled campaigns and imported level packs keep their identity when macOS
  opens the app from a temporary location.
- The skill panel returns to full height after you start a level from a menu.
