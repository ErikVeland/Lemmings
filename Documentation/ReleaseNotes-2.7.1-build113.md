# Ultimate Lemmings 2.7.1

Build: 113
Release base: v2.7
Platform builds: Mac 113, iPhone/iPad/Duo 48, Apple TV 23

## Home background

The level backdrop sharpens from large pixel blocks as Home opens.
Reduce Motion and Static Home Screen show the sharp image immediately.

## Level loading

Longer level loads show a pixel-art intro. With menu music enabled, the intro can play
a random track if the game is still loading. The game starts as soon as it is ready.
Reduce Motion and Reduce Flashes hold the artwork still.

## Compatibility

macOS 12.3 or later on Apple silicon and Intel.
