# 1.8.x consolidation

The development branch is `feature/1.8.x`. This joins the current development
and release histories without publishing a new build. L2/L3 completion remains
a 1.9 gate. The app version and signed public feed remain at 1.8, build 64.

All 26 active local and remote branch references inspected on 6 October 2026 are ancestors
of the consolidated branch. The merge retains `learning-11` and `curriculum-5`,
including the stricter beginner safeguards and both explicit editorial exclusions.
The generated report contains 192 lessons from 1,717 candidates. Session ownership,
recovery, replay controls and the Intel image-interpolation fix are retained.

The older `beautiful-lewin-0d9b49` worktree supplied three test fixes: omit the
unused updater from the standalone movie test, allow a cold encoder to start in
rapid frame-production tests, and cancel the countdown before measuring simulation
throughput. The stalled-encoder test retains its short deadline.

Other edits in that worktree and the `macos12` worktree are already represented
or superseded by the current code: offscreen test placement, serial test execution,
record schema checks, settings-window isolation and updater linkage. Both worktrees
and their original edits are preserved. Tracked patches were also saved locally
under `.build/consolidation-1.8.x/` before the merge.

The old automatic stash is preserved. Its journey test matches the current file;
its older journey and difficulty outputs are superseded by the merged manifests
and replay evidence. It was not applied over newer data.

Three archived branches remain available as history:

- `archive/feature/hint-release-rate-context`: its patch is already in the branch.
- `archive/macos12-support`: the sleep compatibility and loop-buffer fixes are
  already in the current implementation.
- `archive/worktree-phase-0-shared-camera`: an earlier camera/input prototype.
  Its old key map conflicts with the current controls, including Z zoom, and its
  engine-divergence document describes capabilities that have since changed.
  It remains archived rather than replacing the current gameplay controls.

starts, then detected an obsolete test assumption that the first lesson was
“Just dig!”. The test now reads the first lesson from the curated manifest. It
still checks new-run identity, saved history, ownership and a paused handover.

artwork comparison. The original failures are retained in the local logs.

not link into its macOS 12.3 test target. The corrected run used the fresh 12.3
