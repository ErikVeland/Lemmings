The release notes cover all changes since 1.1 RC1 (build 37).

## Release gates

`Scripts/build-and-notarise.sh` built all three targets. All gates passed:

- Rescue proofs and level hints match the engine.
- The app integration tests passed on the standard build.
- Apple notarised the standard and Monterey targets. Gatekeeper accepted both.
- Each target passed the launch smoke test with an empty home.
- The update archive is below the 2 GiB GitHub asset limit.

The bundled soundtrack is AAC at 192 kbps. The lossless source library made
the archive 4.0 GB, which GitHub rejects.

## Actual upgrade

The test started from the public build 41 archive (SHA-256 `546d9ba2…`).
Sparkle 2.7.3's command-line driver updated it from the live feed. It
downloaded, verified and installed the archive, and reported
`Installation Finished`.

The installed app changed from 1.2 build 41 to 1.5 build 50. It passed strict
signature checks, stapled-ticket validation and Gatekeeper
(`Notarized Developer ID`). Its binary was identical to the binary in the
release package. A second probe found no newer update.

## Update behaviour

Build 41 installs updates without a prompt, so existing players receive 1.5
automatically. From 1.5, Sparkle shows the release notes and the player
chooses to install. The app offers no automatic-install option.

## Limits

This is distribution and startup evidence. Physical Intel and minimum-macOS
testing remain unverified. The Game Center target is development-signed for
registered Macs and is not published. The yippee event has no sound with the
Mac sound set.
