# Calendar access in Ultimate Lemmix for Mac

Use Mac build 114. Desk Clock shows the title and countdown for the next timed event. The app and widget read Calendar locally. They do not create or change events.

1. In Calendar, create a timed event named “Clock check” about ten minutes from now. Make it the next event across your calendars.
2. Open Ultimate Lemmix. In the macOS menu bar, choose **Ultimate Lemmix → Show next event in Desk Clock widget…**.
3. When macOS asks for Calendar access, allow full access. If you previously denied access, enable Ultimate Lemmix in **System Settings → Privacy & Security → Calendars**.
4. On macOS Sonoma or later, Control-click the desktop and choose **Edit Widgets**. On earlier versions, open Notification Centre and choose **Edit Widgets**.
5. Search for **Ultimate Lemmix**, then add the medium **Desk Clock** widget. Close the widget gallery.
6. Look below the clock digits for **Clock check** and the countdown. The gallery preview shows only the clock. The installed widget displays calendar events after WidgetKit refreshes its timeline.

A timed event must start within the next 24 hours. Desk Clock skips all-day events and declined invitations. You can play the game without calendar access or a game account.
