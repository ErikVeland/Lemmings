# 1.8.x community-referenced journey

Historical evidence for learning-12. Superseded by [the full 292-level journey and world-anchored effects](1.8xFullJourneyEffects.md).

This update replaces the replay-score selection behind Oh My! All Lemmings!
with `learning-12`, `curriculum-6` and the `redux-community-1` placement policy.
The branch remains `feature/1.8.x`. This is a local test build, not a public release.

## Placement and limits

[Current order and review policy](../../Artifacts/LearningJourney/README.md)
records the 99 selected Classic levels and all source and review evidence.
[Lemmings Redux](https://www.lemmingsforums.net/index.php?topic=4374.0)
provides the community reference order. Its NeoLemmix variants are not assumed
to be identical to the Classic versions.

The former selection used replay effort, blanket rescue/release-rate floors,
skill-pattern deduplication and cumulative score clamping. The production
exporter no longer calls that experimental scoring path. Current runtime loading
requires community placement metadata tied to the exact source and replay.

The revised path contains 23 Fun, 20 Intermediate, 31 Difficult and 25 Expert
lessons. All 99 have bundled winning solutions. Repeated practice is allowed.
Twelve matched counterparts are held for review because their rescue fraction
is over ten percentage points higher than Redux, or their available solution
skills are scarcer. These guards detect uncertain transfers, not measured
human difficulty. The largest remaining gap spans eight Redux positions.

The source audit covers all 1,720 candidates. A further 1,621 candidates remain
outside the mandatory path, including unreviewed fan levels and official levels
without an admitted counterpart. They remain available in the normal library.
The review queue records actual skills, rescue margins, release cadence, route
execution, timing coverage and unknown discovery difficulty. Native replay
hashes prevent a different winning route from inheriting another route's profile.
One stale candidate route was rejected by that check.

No new human playtest results have been invented. The reference order improves
the basis for placement but does not prove a smooth novice experience. Classic
time limits, timed bombers, hidden information and physics differences still
need variant-specific observation. Fan admission requires an exact-version human
solution review with discovery/resource notes and nearby reference comparisons.
L2/L3 remain outside this Classic journey and retain their 1.9 completion gate.

## Saved sessions

Older built-in journey queues migrate when loaded. A retained current lesson
stays current. A withdrawn current lesson moves to the first unvisited reference.
Past visits, progress records, run identity and Solo/Hot Seat ownership remain.
An exhausted queue closes without adding wins. Custom playlists and newer journey
versions are not migrated. Store writes retain the existing backup and stale-writer
protection. Tests use temporary stores and do not migrate the user's real data.
