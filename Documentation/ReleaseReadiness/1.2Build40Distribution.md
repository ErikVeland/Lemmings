# 1.2 build 40 distribution verification

Verified 25 September 2026 on Apple silicon with macOS 27.2.

## Change and release

Build 39 created its lazy Sparkle controller only from the manual update action.
Build 40 creates it at application launch so scheduled updates can start.
The release checker now rejects a feed whose highest build or version does not
match the app metadata, including feeds using enclosure attributes.

## Actual upgrade

A separate, unmodified, signed build 39 app was running before this test.
Sparkle 2.7.3's official command-line user driver performed the update through
its normal updater and installer implementation. It used the candidate feed at
commit `6a290aad5c842126a1027e9b9deeed90291ec029` and the public HTTPS GitHub asset.
The release remained a prerelease until this test passed.

The driver downloaded all 428869969 bytes, verified and extracted the archive,
reported `Installation Finished`, and exited successfully. The installed app's
plist changed from build 39 to 40. Sparkle relaunched the app through launchd.
A process sample confirmed that the new process was build 40 and remained in
its AppKit event loop. The installed copy passed deep, strict signature checks,
stapled-ticket validation and Gatekeeper (`Notarized Developer ID`).

After promotion, the live main-branch appcast matched the generated feed exactly.
With no feed override, Sparkle's probe reported `Update available!` for the
original build 39 and `No new update available!` for the installed build 40.
The public GitHub API confirmed the latest release and matching archive digest.

An earlier localhost feed request timed out. The old app remained running at
build 39 after that failed request. No security settings were changed to bypass
that failure; the successful test used public HTTPS.

## Limits

Native desktop automation timed out when reading the game's accessibility tree,
so the menu-click journey was not directly driven. The verified upgrade used
Sparkle's official driver and real installer, and the actual app relaunched.
This is distribution and startup evidence, not new gameplay validation.
Physical Intel and minimum-macOS testing remain unverified. Existing sequel
preview status, artwork-toggle and controller sequence limits remain documented
in the release notes.

Build 39 users can select **Ultimate Lemmings → Check for Updates…**.
For a new installation, expand the ZIP and move the app to Applications.
