# 1.8 sequel verification record

## Scope and source

The 1.8 exit gate covers all 120 Lemmings 2 levels and all 90 Lemmings 3
levels. It also requires continuous campaigns, source-engine rule comparisons,
endings, media, saved-run recovery and result identity. Keep both games labelled
Preview until the full gate passes.

This check started on 29 September 2026 from `release/1.7.0` at
`2e15cc14f87328809ab31e80255ab7e159b62780`. The Mac ran macOS 26.5.2
with Xcode 26.6. The working tree had four unrelated modified files before
this check. They were left untouched. This is a working-tree check, not a
frozen release candidate.

## Original walkthrough cross-check

From `83b5d05`, the bundled L3 Shadow level 106 was rendered and its native
object lists inspected. Its permanent object file contains no shimmier tool
identifier `5003`. A [PC Chronicles walkthrough](https://www.cheatbook.de/wfiles/lemmingschronicles.htm)
uses a shimmier pickup in its Shadow level 6 route. That route is unsuitable
as a seed for this bundled level without further source-version comparison.
No fixture was added. The local `LEVEL106.DAT` and `PERM106.OBS` SHA-256
values were `9a16a9e94700b0e827b297411f6bdffe994abe1d6c3c96a810a3ab83f44bea42`
and `508a0436b786277d997481508b75bc8a6e45b91c5294d9e8b4de92abff9c61ea`.

The same walkthrough describes Classic level 6 using bricks and a spade. The
bundled level 006 has those tools, including brick boxes beyond the
starting area, so it is a better guide candidate. Its prose implies more than six uses from the first
brick box, while the current preview gives each brick box six. This is a
source-engine quantity question, not proof that the preview is wrong. Resolve
it against the original game before changing tool rules or promoting a guided
route.

A [contemporary Amiga gameplay document](https://www.lemonamiga.com/doc/all-new-world-of-lemmings/59)
shows eight uses for a brick pickup. It does not establish the DOS CD rule.
From `e2894c1`, a temporary eight-use brick and spade setting was used only
for one bounded Classic level 006 search. With a 90-second solver budget and
initial beam 128, it expanded 684,253 states and found no win. The six-use
source was restored after the run; no candidate or fixture was retained.
The quantity question remains open.

From `38768f8c0286f178cccc985ec0ff76a8d363f2b5`, a guided Classic
level 006 search turned the first lemming left at tick 56. The native runtime
accepted the input and the lemming collected the first brick pickup. With the
unchanged six-use rules, beam width 128, maximum depth 220 and a 120-second
limit, the standard ranking expanded 119,414 states in 11 seconds and found
no win. The fewer-inputs-first ranking expanded 195,893 states in 17 seconds
and also found no win. Both searches exhausted their reachable beam before
the time limit. No replay candidate or fixture was written. This checks one
early turn from the walkthrough; it does not resolve the quantity or rule
parity question.

From `5555b302a91b254da936733ba7796a7d2bbca721`, the repository L3 solver
searched previously untested Classic levels 020, 022 and 023 with a 45-second
limit and initial beam width 128 per level. Three widening rounds reached
beam width 512 in each run. The searches expanded 954,407, 728,409 and
853,672 states respectively. None found a winning route, wrote a candidate
or changed a fixture. These bounded failures leave all three route gaps open.

`zsh Scripts/run-lemmings2-runtime-tests.sh` and
`zsh Scripts/run-lemmings3-runtime-tests.sh` with the supplied local game data.
The Mac ran macOS 26.5.2 and Apple Swift 6.3.3. The Command Line Tools were

The L2 suite loaded and advanced all 120 levels through native physics,
replayed 73 distinct recorded completions and selected Cavelems and Circus
carry-over routes. It passed twelve-tribe progress, medal thresholds, save
round trips, invalid-save rejection and ark eligibility checks. The
all-gold ending state in this suite is constructed campaign data, not a

The L3 suite checked the 30-level inventory for each tribe, selected Classic,
Shadow and Egyptian winning runs, survivor and reserve carry, isolated tribe

trap types. It did not complete all 90 levels, compare a DOS result or test a
packaged app session. These source checks narrow the campaign-state risk but
do not close the 1.8 exit condition.
