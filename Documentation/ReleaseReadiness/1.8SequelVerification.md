# 1.8 sequel verification record

## Scope and source

The 1.8 exit gate covers all 120 Lemmings 2 levels and all 90 Lemmings 3
levels. It also requires continuous campaigns, source-engine rule comparisons,
endings, media, saved-run recovery and result identity. Keep both games labelled
Preview until the full gate passes.

This check started on 29 September 2026 from `release/1.7.0` at
`2e15cc14f87328809ab31e80255ab7e159b62780`. The Mac ran macOS 26.5.2
with Xcode 26.6. The working tree had four unrelated modified files before
this check. They were left untouched. This is a working-tree check, not a
frozen release candidate.
