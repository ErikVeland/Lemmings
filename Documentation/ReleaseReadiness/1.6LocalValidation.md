## Upgrades keep the soundtrack

Sparkle replaces the whole app bundle. The 1.5.0 bundle holds all 495 versions,
so an update that bundles only 54 would delete the other 441. The Sparkle update,
Monterey and Game Center builds therefore carry the full soundtrack as AAC.
Only the public fresh-install download, `-slim.zip`, bundles 54 versions.

AAC copies differ from the analysed lossless files. `library.py playback` records
each copy's hash as `playbackSHA256` in the bundled timing and rhythm indexes.
Rhythm loops stay lossless. `build-and-notarise.sh` fails when a full build would
offer a library for download, or when a slim build bundles one.
