# Shared 2.1.3 release checklist

Status: draft, 22 October 2026. Scope is not frozen. No 2.1.3 build exists.

One release covers macOS, iPhone, iPad, iPhone Duo and Apple TV. Use one
source snapshot and one marketing version. Each platform has its own build
number and delivery receipt. The baseline is [2.1.2](2.1.2Checklist.md).
Evidence for 2.1.2 does not certify changed source.

Key: `[ ]` open. `[x]` done with evidence. `[w]` human device check, waived by
the owner on 22 October 2026. A waiver is not a pass. No device result exists for it.
