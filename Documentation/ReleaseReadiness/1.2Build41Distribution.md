# 1.2 build 41 distribution verification

Verified 25 September 2026 on Apple silicon with macOS 27.2.

Build 41 fixes the launch fault in builds 39 and 40 (issue #3). It also has the
fixes and release gates in the build 41 release notes.

- Source: `2001bc3b05e4fec93a65a69c7aa594a9c41b1e51`.
- Public release: https://github.com/ErikVeland/Lemmings/releases/tag/v1.2-build41
- Archive: `UltimateLemmings-1.2-build41.zip`, 428870383 bytes.

- Live feed: `main` commit `46cc95a26d3f4a665bbaa762ab0d2ef3c6195aad`.

## Release gates

`Scripts/build-and-notarise.sh` built all three targets. All gates passed:

- Rescue proofs and level hints match the engine.
- The app integration tests passed on the standard build.
- Apple notarised the standard and Monterey targets. Gatekeeper accepted both.
- Each target passed the launch smoke test with an empty home.

The Sparkle signature of the update archive matched the public key in the app.

## Actual upgrade

An unmodified build 40 from the public release was running before the test.
Sparkle 2.7.3's command-line driver updated it from the candidate feed at
commit `059aa7f3c933ebe1b8bdaa8b11815d60f01c0420`, over public HTTPS.
The release stayed a prerelease until this test passed.

The driver downloaded, verified and installed the archive, and then reported
`Installation Finished`. The installed app changed from build 40 to 41. It
passed strict signature checks, stapled-ticket validation and Gatekeeper
(`Notarized Developer ID`). Sparkle relaunched the app. The running binary was
identical to the binary in the archive. A second probe found no newer update.

After promotion, the live `main` feed matched the signed feed exactly. With no
feed override, Sparkle reported `Update available!` for an unmodified build 40.

## Limits

This is distribution and startup evidence. Physical Intel and minimum-macOS
testing remain unverified. The Game Center target is development-signed for
registered Macs and is not published.
