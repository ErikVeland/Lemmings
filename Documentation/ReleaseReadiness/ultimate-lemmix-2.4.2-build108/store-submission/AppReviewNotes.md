## Review notes

Ultimate Lemmix is a puzzle game with three included starter levels:
**First Steps**, **Float to Safety** and **Over the Rise**. These levels need no
original game files or hosted account. The app includes alternative artwork and
music with their licence notices.

Additional game-data import is optional. The app accepts player-selected data
for supported Classic, Lemmings 2, Lemmings 3 and NeoLemmix content. It does not
include original commercial game media. Imports do not run the original game
application or install executable code.

On Mac, use the app's file-selection controls. On iPhone and iPad, open
**Settings > Game Data** and choose the relevant import or **Restore original
assets** action. Apple TV displays a temporary local-network address for the
same transfer. Keep both devices on the same local network during transfer.
No original game files are needed to review the three starter puzzles.

The app retains solo play, local Hot Seat play, saved journeys, records, hints,
replays and accessibility controls. A Hot Seat handover stays paused until the
next player is ready. Available routes depend on the installed game data.

Cloud saves synchronise automatically and preserve player profiles, progress,
shared campaign participants and turn ownership. The app uses private iCloud
storage and an encrypted hosted library. Linking devices is optional and does
not require an email-based account. Game Center is a separate optional service.
Compatible Mac and iOS solo progress can also use Game Center saved games.
Apple TV uses the cloud library for progress.

**Share counts and records** is a separate consent choice. It sends aggregate
play counts and enables community records for players without an explicit
record-sharing choice. Public records include initials, scores and action
replays. Players can change sharing or request removal of shared records.
Local play remains available without count or community record sharing.

Calendar access is optional. Desk Clock reads the next calendar event for its
signpost display. The app does not edit the calendar or upload calendar events
to its cloud-save or count services. The Mac and iOS widgets use the same clock
presentation. Apple TV Top Shelf uses locally shared scenery.
