# 1.2 data-independent handoff

Updated 24 September 2026.

This record covers work that does not need new Lemmings 2 or Lemmings 3 level
data. It does not close the 1.2 sequel completion gate.

## Implemented in source

- The shared content browser and playlist storage are present.
- The fan-pack update check runs sequentially and validates archives before install.
- Sparkle 2.7.3 checks the signed application feed and supports automatic updates.
- The build script creates the update archive and signed appcast.
- The GitHub release script uploads the update archive and publishes the appcast.
- The release-input check validates the 1.2 metadata, Sparkle pin, feed and scripts.

## Verified in this checkout

Run these checks before the release build:

```sh
zsh Scripts/check-1.2-release-inputs.sh --allow-empty-appcast
python3 -m unittest discover -s Tests/ReleaseReadinessTests -p 'test_*.py'
```

The empty-feed option is valid only before the first public update exists. The
notarisation script runs the strict check after it generates the feed.

## Release Mac checks

Run the full notarised build with the local credentials and level data. Install
the previous build before testing the update. Confirm that the app downloads,
verifies, installs and relaunches at the new build number.

Record the archive checksum, appcast checksum, source revision and Gatekeeper
result. Test update failure recovery before removing the previous build.

Run the physical controller, VoiceOver, display, sustained-speed, audio,
sleep/wake, power-loss and installed-release migration checks on that Mac.

## Data-dependent 1.2 gate

The 96 missing L2 and L3 winning routes remain open. The sequel gate also needs
engine-fidelity, campaign-progression, media, recovery, replay and ending
evidence. Keep both sequels labelled Preview until those checks pass.
