## Test repairs

The first sequel run reused settings after an HD check deliberately selected
Custom. The next check incorrectly expected Modern. Giving that check a fresh
settings instance resolved the failure. The sequel test script also needed the
Sparkle framework link used by the app.

Two full-app runs were stopped during repeated fan-pack progress redraws. The
integration entry point bypassed normal startup and did not seed the packaged
fan-count index. The corrected fixture loads that index exactly as production
startup does. These stopped runs are not counted as passes.

The separate remainder runner initially omitted the music-library setup from the
earlier music test. It stopped when the seasonal check indexed an empty catalogue.
The scratch runner was corrected to load the same module and soundtrack fixtures;
this was not a failure in the shipping startup path. The seasonal check also
changed campaigns directly without resetting the playback identity used by real
level starts. The journey check assumed an obsolete second lesson. Tests now reset
the direct-switch identity, check the current generated teaching order and verify
the snow-art fixture separately. The corrected remainder passed. The app binary
and production resources did not change.
