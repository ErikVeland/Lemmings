# 1.3 mobile source handoff

Date: 25 September 2026

## Scope

This handoff covers the data-independent iPhone and iPad source milestone on
`codex/1.3b`. The player-facing application imports Classic DOS content that
the player owns. Lemmings 2 and Lemmings 3 have shared session and recovery
adapters, but they do not yet have player-facing mobile import and rendering.

## Local result

- All 42 package tests in seven suites pass with Xcode 26.6. This includes all
  13 `LemmingsMobileCoreTests` and a data-independent Classic jumping regression
  for the optimised runtime.
- Xcode compiles the Debug app and test bundle for arm64 and x86_64, and the
  optimised Release app for arm64 and x86_64, with the iOS 26.5 Simulator SDK
  when the asset catalogue is excluded. It also compiles an unsigned optimised
  Release app for the arm64 device SDK.
- The asset catalogue is structurally valid and contains the 1024-pixel app
  icon.
- This Mac has no installed iOS Simulator runtime and no connected iPhone or
  iPad. It cannot provide launch, rotation, asset-compilation or physical-device
  evidence.

These results are source evidence only. They do not close the iPhone and iPad
release gate.


Expected result:

```text
PASS 1.3 mobile project, target and source contracts
PASS 1.3 tests, Debug and Release Simulator builds, and unsigned Release device build
```

## Run the UI matrix

Run the shared `UltimateLemmingsIOS` scheme on one available iPhone and one
available iPad. The committed GitHub Actions workflow selects both device
families and runs the first-launch and rotation journey.

For a manual run, replace `DEVICE_ID` with an available Simulator identifier:

```sh
xcodebuild test \
  -project Apps/UltimateLemmingsIOS/UltimateLemmingsIOS.xcodeproj \
  -scheme UltimateLemmingsIOS \
  -destination "platform=iOS Simulator,id=DEVICE_ID" \
  CODE_SIGNING_ALLOWED=NO
```
