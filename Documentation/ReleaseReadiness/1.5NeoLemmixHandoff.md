# 1.5 NeoLemmix source handoff

- Date: 25 September 2026
- Branch: `codex/1.5`
- Implementation commit: `2fa4ab20e023050b0aad26b8172e8a1fcfcb2e7a`

## Decision

The 1.5 source lane is ready for continued NeoLemmix compatibility work. The
data-independent source gate, pinned development corpus gate and inherited 1.3
mobile CI pass.

This is not approval to advertise full NeoLemmix compatibility or cut a 1.5
release. Strict runnable, reference-replay, visual parity and distribution
rights gates remain open.

## Reference contract

The implementation uses
[NeoLemmix Community Edition 1.2.0](https://github.com/Willicious/NeoLemmixCommunityEdition)
at commit `38d0449f87501798e78ac668a9494848f4aa9649` as the current source oracle.
The public CI does not download CE levels, styles or other assets. Local corpus
checks require content that the tester may lawfully use.

## Implemented baseline

- Current section-based `.nxrp` metadata and command decoding, with explicit
  rejection of legacy replay text.
- All 21 current skill names are retained. The simulator implements 19 and
  reports Fencer and Laserer as unsupported.
- Current CE object effects, generated animation names, point-sized entrance
  and receiver triggers, integer animation-strip division and small-target
  nine-slice trimming are recognised.
- Level diagnostics separate import or render failures from explicit
  unsupported mechanics.
- The combined gate supports source-only, pinned development-corpus, strict
  runnable and supplied replay-corpus modes.
- GitHub repeats the source-only gate on `codex/1.5` and continues to protect
  the 1.3 iPhone and iPad baseline.

## Open release gates

1. Implement every mechanic named by the strict corpus report, then pass the
   full corpus with `--require-runnable-corpus`.
2. Retain and validate replay selection identity and cross-check fields, then
   run lawfully held `.nxrp` files against their exact levels to the declared
   completion frame twice.
3. Compare native and CE completion frame, result, final state, animation and
   destructive masks. Record every mismatch and accepted limit.
4. Verify pack progress, save recovery, replay identity and changed-content
   rejection in the player-facing application.
5. Confirm the licence and distribution status of every level, style, sound,
   image and replay used for release evidence or packaging.

The reviewed CE checkout contains no reference `.nxrp` corpus. Synthetic replay
tests prove decoding behaviour only; they do not prove replay-result parity.

## Repeat the gates

Run the source-only gate:

```sh
zsh Scripts/check-1.5-neolemmix.sh
```

Run the strict corpus gate:

```sh
zsh Scripts/check-1.5-neolemmix.sh \
  --ce-root /path/to/NeoLemmixCommunityEdition \
  --require-runnable-corpus
```

Run a supplied replay import corpus:

```sh
zsh Scripts/check-1.5-neolemmix.sh \
  --replays-root /path/to/reference-replays
```

Do not change the 1.5 compatibility label from Beta or Preview until the open
gates have evidence and the release owner accepts the residual risk.
