The public release tag, both download hashes and ZIP responses, and the live
main and raw Sparkle feeds passed remote verification.
See the [public verification log](1.8.5-build74/live-publication-check.log).

Frozen release source: `ecafd64c09ca0f87e3ad45d842683ab9b2a4b11d`.

owner when Hot Seat queues another player. Collection shortcuts preserve locks

and [collection guide](../LevelCollections.md).

## Validation

The fresh [minor audit](1.8.5-build74/audit/report.md) passed 47 checks with zero
source drift. Its GPU check could not access Metal inside the filesystem sandbox.
The same compiled check [passed outside that sandbox](1.8.5-build74/hdr-gpu-final.log),
using the offscreen, muted runner. The original failure remains in the audit log.
All 48 required checks therefore have passing evidence for this source.
Five broad app, movie, sequel, arcade and performance groups were not run by
that audit. The focused native checks below supplement it.

The [native collection and flow checks](1.8.5-build74/collections-runtime.log)
passed with `Tools/UITestRunner/run.py`, offscreen windows and
`LEMMINGS_TEST_AUDIO=muted`. They cover four-engine reference resolution,
personal storage, relaunch, recent ordering and retention, backup recovery,
stale-writer rejection, saved and unsaved stars, result owner identity,
locked/missing/changed cards, three window sizes and input targets.
They also cover Classic, fan and NeoLemmix checkpoint restoration, paused retries,
Hot Seat ownership and Ready handovers, and saved Solo/Hot Seat choices across
Classic, L2 and L3. An older synchronous retry fixture now waits for the app's
existing background rescue-target validation before checking its result.
The [release-tool suite](1.8.5-build74/release-tools.log) passed all 36 tests.
[What's New captures](1.8.5-build74/release-notes-layout/900-top.png) verify clipping,
scrolling and the Continue action at three sizes.

The shared simulation, level data and artwork did not change. The minor-release
policy retained the existing winning-route evidence and checked its manifests.
This run did not replay every campaign. L2/L3 remain Preview and NeoLemmix remains
Beta. L2 practice scenes and standalone NeoLemmix files have no catalogue launch
route and remain outside collections. Physical Intel, minimum-macOS, controller,
VoiceOver listening and audible-audio journeys remain unverified.

## Packages

application and shared-library slices with a macOS 12.3 deployment target.

495 music versions, 422 playback profiles, current proofs, hints and learning
journey, rescue MP3, sequel inputs and frozen source hashes.

music bytes, catalogue, playback profiles and optional-library archive bindings.

strict signatures, ZIP integrity and Gatekeeper assessment after extraction and

[notarisation receipts](1.8.5-build74/publication.json).
