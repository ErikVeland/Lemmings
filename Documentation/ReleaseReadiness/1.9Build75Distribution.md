# 1.9 build 75 distribution evidence

Published 10 October 2026: [Ultimate Lemmings 1.9, build 75](https://github.com/ErikVeland/Lemmings/releases/tag/v1.9).
The release tag, both download hashes and ZIP responses, and the live main and
raw Sparkle feeds passed remote verification. See the [publication log](1.9-build75/publish.log)
and [archive receipts and hashes](1.9-build75/publication.json).

Frozen release source: `6eb9e174b9663f3dc3f85aff62cfa5f923b718c5`. Release base: `v1.8.5`. Tag: `v1.9`.

Lemmings 2: The Tribes is Complete and leaves beta. Lemmings 3: Chronicles moves
from Preview to Beta. The owner approved these release classifications on
10 October 2026. See the [release notes](../ReleaseNotes-1.9-build75.md)
and [release scope](../ReleaseScope.md) for the evidence and its limits.

## Validation

The fresh [minor audit](1.9-build75/audit/report.md) passed all 48 checks with zero
source drift. This includes native engine regressions, save and cross-build
recovery, retained route manifests, package and update contracts, hints, input
policies and offscreen GPU output. Five broader audit groups were not run:
replay movies, the complete app suite, performance measurement, sequel views and
arcade records. Focused native checks supplement that audit.

All native UI checks used `Tools/UITestRunner/run.py`, its default offscreen
windows and `LEMMINGS_TEST_AUDIO=muted`. The passing scopes cover:

- [Macintosh fidelity](1.9-build75/mac-fidelity-runtime.log): original MousePress
  sample and pitch, actual and queued rate input, unchanged and locked limits,
  original counter glyphs and accessible targets, 31 lossless music files,
  all six campaign selections, special-theme fallback and pause recovery.
- [Saved progress and Hot Seat](1.9-build75/exit-progress-runtime.log): completion
  callbacks save Journey wins before Next, retain the attempt owner and reject
  stale results. Menu, Q and Escape save and return in all three engines.
  Resume shows two and eight players in order, with wrapping and input targets.
- [Updates](1.9-build75/updates-runtime.log): busy icon/menu requests, coalesced
  clicks, repeated focus, automatic notes, cleanup and retry without restart.
- [Release UI](1.9-build75/release-ui-runtime.log): actual bundled Tribes Complete
  and Chronicles Beta labels, typed catalogue families and scrollable notes at
  three sizes, with usable Continue and Settings targets.
- [Music](1.9-build75/music-runtime.log): all 25 available source transitions,
  seasonal/fan handovers, saved settings, global mute, interruption recovery,
  paused retries and Hot Seat attempt ownership.

The [release-tool suite](1.9-build75/release-tools.log) passed all 36 tests.
[Home status](1.9-build75/screens/home-status.png), [eight-player Resume](1.9-build75/screens/classic-8-640.png),
[Macintosh counters](1.9-build75/screens/classic-900-macintosh.png) and
[What's New](1.9-build75/screens/900-top.png) retain rendered evidence.

The fresh [strict L2 replay](1.9-build75/l2-completion.log) verified all 120
standalone wins, 70 carry-over variants and all twelve ten-level tribe chains.
[Event and negative checks](1.9-build75/l2-events-negative.log) and
[chain gates](1.9-build75/l2-gates.log) also pass. The chains finish with one
survivor; the golden-talisman ark ending remains unverified.
The [L3 gate](1.9-build75/l3-completion.log) retains 74 of 90 standalone wins,
155 carried-population routes and 68 prefix results. Sixteen standalone routes
and the three campaign/ending chains remain open.

The [replay catalogue refresh](1.9-build75/refresh-proofs.log) re-audited all 562
levels and 615 configurations, retained every published rescue target, and
packaged 294 exact-condition certificates and 303 best-known rescue records.
Classic and L3 simulation rules are unchanged from 1.8.5; the release includes
fresh native L2 climbing, stone-collision and runtime corrections.

## Packages

Fresh optimized arm64 and x86_64 application and shared-library slices target
macOS 12.3. The [build log](1.9-build75/build.log) records both compiles. A build
retry initially copied a nested baseline app; that extra copy was removed from
the candidate before signing. The final package closure and strict signatures
pass. The release reuses the unchanged 1.8.5 game and soundtrack assets, adds the
31 prepared Mac arrangements, and copies current proofs, hints, progression and
third-party notices. Package checks verify all 495 soundtrack versions,
422 playback profiles, rescue audio, sequel inputs and frozen source hashes.
The [slim closure check](1.9-build75/slim-closure.log) verifies every retained
music file and optional-library archive binding. Both variants retain Mac music. Both archives are below
[GitHub's 2 GiB asset limit](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases#storage-and-bandwidth-quotas).

Both downloads pass Developer ID signing, Apple notarisation, ticket stapling,
strict signatures, ZIP integrity and Gatekeeper assessment after extraction with
Safari quarantine. See the [package log](1.9-build75/package.log) and
[nested signatures](1.9-build75/nested-signatures.log), which verify one Developer
ID team and hardened runtime for the app, library and Sparkle components.

The feed retains all six previous entries and their enclosure attributes.
The main branch contains the frozen release source before the feed is published.

A foreground launch of the signed shipping app was not run. The repository's
smoke test requires a foreground window, which needs a new explicit user request.
Original-Mac listening comparisons, physical Intel, minimum-macOS, controller,
VoiceOver listening and audible-audio journeys remain unverified. The release
classifications do not close original-engine fidelity or high-survivor ending gates.
