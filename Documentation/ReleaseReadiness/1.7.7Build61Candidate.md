# 1.7.7 build 61 candidate validation

Published as 1.7.7 build 61. See the [distribution record](1.7.7Build61Distribution.md).
Frozen source: `17498ea029200507d6064ce897d6711f45938079`.
Release base: v1.7.6. Universal arm64/x86_64, macOS 12.3 minimum,
full soundtrack with 495 versions.

The candidate includes the revised nuke filter, larger skill icons, smaller
optional count, optional Classic skill backpacks and both cursor styles. The
Original cursor uses the supplied Amiga PNG colours and transparency.

## Checks

- The minor audit passed 48 checks with zero failures and no source drift.
  Five optional checks were not run by that audit. Separate app evidence follows.
- 32 release-tool tests and 14 difficulty-tool tests passed.
- Official Classic and conversion verification passed all 352 routes,
  1,056 saved-run recoveries, 352 progress resumes, six chapter transitions
  and the final result. Negative checks rejected missing and changed fixtures.
- Rescue verification retained 251 exact-condition certificates and 17 rescue
  records. The hint exporter passed all 352 routes. Bundled solution validation
  checked 350 stored fixtures. Engine fingerprints were regenerated and agree.
- Offline audio checks passed the nuke filter sweep, bass limits, pause, speed,
  rewind and recovery. Adaptive DJ mix checks passed without hardware playback.
- Native playfield checks passed backpack rendering and opt-out, skill icon/count
  geometry, pointer targets, zoom, Retina and edge clipping.
- The release UI scope passed cursor presets and settings persistence in Classic,
  L2 and L3, backpack controls, pause input, dialogs, nuke, saved-run recovery,
  all 292 learning entries, journey starts and Solo/Hot Seat session ownership.
- The welcome page was reviewed as a bitmap. An initial clipped paragraph was
  shortened, rebuilt for both architectures and checked again.

The 48-check audit used source `01a6879` and the accepted 1.7.6 resource bundle.
The only later source change was welcome-page prose. Release-note prose also
records the fan replay limits below. The final app checks use the new 1.7.7
bundle. Its version, hints, rescue proofs and progression bytes match source.
All 1,307 port, 4,241 Mac-artwork, 3,158 Amiga-artwork, 648 music,
537 fan-pack and 4,001 NeoLemmix resource files match the accepted 1.7.6
bundle byte for byte.

All automated native UI tests used `Tools/UITestRunner/run.py` offscreen with
audio muted. The release-tool audit did not run optional replay movies,
performance measurement, standalone sequel views or arcade-record checks.
Its generic app check is covered here by the recorded focused release UI scope,
not by a claim that the complete integration suite passed.

## Fan replay limits

A strict replay of the diagnostic Golems alternatives did not complete on this
candidate. Bridge Doom still rescues 74 at tick 2531 but has a different final
state hash. Seems simple enough...but rescues 68 at tick 2428 rather than the
stored 2430. A separate ordinary-assignment check of the selected Pass
Interference route rescues 30/30 at tick 1020 rather than the stored 1021.
These are not exact replay passes. The stored witnesses and their expectations
were not rewritten to hide the mismatches. Release notes retain the source
physics qualification. Other diagnostic alternatives were not re-certified.

The source-action derivation verifier could not run because its ignored
`lldb-all-records/manifest.json` input is absent. Earlier derivation records
are not newly verified by this release. L2/L3 remain Preview and NeoLemmix
remains Beta.
