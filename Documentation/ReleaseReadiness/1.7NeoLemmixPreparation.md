## 27 September pickup, button and paint follow-up

The simulator now handles one-use skill pickups and exit buttons with locked
exits. Focused tests cover zombie exclusion, pickup order, finite skill stock,
same-tick exit unlocking and save restoration. The static renderer now clips
paint objects to terrain, and its focused pixel test passes. The checked
replay source, simulator and renderer suites pass. The end-to-end suite passes
after its unsupported-gadget fixture changed from locked exit to splitter.

The full pinned CE corpus run after pickups, buttons and locked exits imported
and rendered all 794 levels. It ran 239,753 deterministic ticks, reported
5,671 warnings, 37 levels with unsupported mechanics, and no import or render
failures. Strict mode exited with a failure. This run preceded the paint
change. A focused run on `A_New_Coat_Of_Paint.nxlv` after that change reported
only Fencer and Laserer as unsupported. Paint no longer appears in its
unsupported list. That check does not prove CE visual parity.

No real reference replay corpus is available in the reviewed local trees or
the pinned CE checkout. Replay results, final CE state, winning routes,
animated gadget states, and player-facing recovery still need evidence. The
remaining strict corpus categories include Fencer, Laserer, teleporters,
updrafts, force fields, splitters and zombie infection. The current source
does not satisfy the 1.7 compatibility exit conditions.

## Repeatable checks

Run the existing source gate from the repository root:

```sh
zsh Scripts/check-1.5-neolemmix.sh
```

When a pinned CE checkout is available, run its development corpus gate:

```sh
zsh Scripts/check-1.5-neolemmix.sh \
  --ce-root /path/to/NeoLemmixCommunityEdition \
  --require-ce-corpus
```

The 1.7 compatibility claim needs the strict runnable corpus, matched real
replays, visual and behaviour comparisons, recovery, and cleared content
rights. The CE source licence is CC BY-NC 4.0, while its images, music and
sound retain separate copyright restrictions. Keep oracle data local and do
not copy it into the app package. The [1.7 roadmap](../1.7Roadmap.md) owns
the exit conditions.
