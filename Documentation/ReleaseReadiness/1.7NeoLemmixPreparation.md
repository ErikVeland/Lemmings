Prepared 26 September 2026 from `release/1.6.0` at
`7e99dbb18f8afe1bf2fedc5e86009b70f2c562e5`. The checkout also has
uncommitted roadmap edits. This record prepares the 1.7 compatibility lane.

## 27 September public replay probe

The public Lemmings DD V1.04 archive supplies 32 NXLV levels, one custom style
and 100 solution or challenge replays. It was downloaded from the pack author's
Lemmings Forums attachment at
`https://www.lemmingsforums.net/index.php?topic=5307.msg88715` and retained
outside the repository. The archive
SHA-256 is
`c3e8c13525100b1f0361e84900a556b2fe5d56ccd30593e6d1a9b0578195fd99`.
No redistribution licence was present, so the content remains local test input.

All 100 replays decode with 2,055 commands and no unknown skill assignments.
They predate CE completion frames and stable lemming identifiers. The source
engine explicitly falls back to `LEM_INDEX` for this generation, so checked
playback now does the same while still requiring the recorded position and
direction. The strict replay-field shell wrapper previously failed to forward
`--require-replay-fields`; it now forwards all validated arguments. The fixed
gate correctly rejects this corpus because every replay lacks a completion
frame.

The new paired-corpus runner matches replays and levels by their recorded IDs,
resolves the supplied and pinned styles, applies the source engine's five-minute
replay-check tail and requires a native win. The first run found 16/100 native
completions. It also exposed a terrain-group renderer mismatch: CE excludes
erasers from the initial bounds and crops the composite to opaque pixels. After
that fix, focused renderer and replay tests pass and the paired run reached
18/100 completions. CE-aligned Digger assignment timing, Builder and Platformer
collision movement, Jumper wall and head probing, shared transition fall setup
and Swimmer diving then raised the same diagnostic run to 24/100 completions.
Slider and Dehoister wall, ledge and water probes now also follow the shared CE
terrain-check routine; the mismatched-version 32-level sample remained 7/32.
A newest-replay-per-level sample first rose from 5/32 to 7/32. Exact Basher,
Miner, Bomber and Stoner masks plus falling Oh-No/Stoner behavior then raised
that sample to 12/32; the final 100-replay run reached 37/100 completions after
trap and teleporter busy-state parity. The remaining 63 failures are retained
as evidence of physics, terrain, skill, gadget or changed level drift; this
corpus does not close replay parity. All 100 replay versions
are older than their supplied level versions, and one replay also lacks the
normal identity metadata. These counts are regression evidence, not a measured
compatibility percentage.

The native recovery path now refuses a retained NeoLemmix state when the
freshly loaded level configuration or terrain differs. Cross-build tests cover
input replay, deterministic continuation, JSON persistence, saved-state
fallback for a later engine and changed-terrain rejection. Exact-version pack
progress and replay-identity journeys remain open.

The native app no longer maps NeoLemmix actions onto DOS sprite stand-ins. It
loads the level theme's lemming scheme and PNG sheets from the player-selected
styles directory, uses direction-specific foot anchors and applies theme,
athlete, zombie and neutral recoloring. Declared alternate shades preserve the
CE HSV offset when the theme changes a primary color, including state-specific
shade swaps, and Jumper frames follow CE's three progress buckets. A
pinned-corpus pass resolves all 794 levels, 59 themes and 15,104 representative
action, direction and state frames. Pixel tests, a rendered contact sheet and
the existing playfield targeting suite verify shade handling, frame selection,
sprite orientation, distinct action states and unchanged foot-coordinate input
targets. Capture-to-capture animated visual comparison remains open.

Button and locked-exit primary animations now retain all source frames. Their
runtime state follows CE's update order: frame 1 while idle/locked, advancement
after lemming processing on the press tick, then a permanent frame 0. A locked
exit with no buttons starts on frame 0. Focused simulation and pixel tests cover
the transition, final-button unlock, stable states and a JSON recovery taken in
mid-animation. CE capture comparison remains open.

Reusable and one-shot traps now retain and render their current primary frame.
Their trigger-tick advancement and return to frame zero follow CE's
post-lemming gadget update, and reusable traps become available on the first
lemming pass after the animation wraps. Focused tests cover the complete frame
cycle and mid-animation JSON recovery.

Foreground gadgets in CE's always-animate set now select their retained
primary frame from the deterministic simulation tick. Entrances remain closed
on frame 1, advance on the configured opening tick, and settle on frame 0.
Splitters select frame 0 or 1 from their current alternating output direction.
Pixel tests cover these states and cycles. Moving backgrounds, secondary
animations and paired teleporter/receiver frames remain open.

Unconditional secondary animations now retain every frame and compose with
their CE offset, Z-order, transform, resize delta and initial state. The live
scene advances playing foreground layers from the deterministic tick.
Trigger-controlled secondary state transitions remain open and continue to
produce a specific warning.

The native playfield now retains the renderer's background, terrain and
foreground planes and recomposites terrain from the current simulation mask on
each changed tick. Focused pixel tests verify background reveal, CE's twelve
construction gradient steps, destroy-then-rebuild provenance and foreground
ordering, including replacement of physically solid but partially transparent
terrain. Completed Stoners use the
player-supplied canonical 16-by-11 `gfx/mask/stoner.png` at CE's exact
foot-relative origin. Each added pixel retains its Stoner owner and source
index, so it does not overwrite existing terrain and remains below foreground
gadgets. The sprite corpus requires that asset, decoded RGBA data and size for
every resolved theme. Capture-to-capture comparison remains open.

After adding this visual provenance, the strict corpus again passed all 794
levels with 5,671 warnings, zero unsupported levels and zero import or render
failures, over 251,064 deterministic ticks. The independent 160-replay Redux
gate retained 160 native and recovered completions, 160/160 recorded rescue
frames and zero failures. Cross-build recovery still accepts older checkpoints,
retains the new optional visual state and rejects changed terrain.

The settled live-primary-animation tree passed the strict corpus with all 794
levels, 251,064 deterministic ticks, zero unsupported levels and zero import or
render failures. It reported 48,434 warnings before unconditional secondary
layers were rendered. The same tree passed 160/160 Redux native completions,
160/160 recovered completions and
160/160 recorded rescue-frame matches. The sprite corpus passed 794 levels,
59 themes and 15,104 state, direction and action frames. Focused pixel tests
cover trap, button, locked-exit, entrance, always-animate and Splitter primary

After unconditional secondary layers were added, the strict corpus retained

## 27 September exact-version Redux replay corpus

A public Lemmings Redux solution archive supplies one replay for each of the
160 levels in the CE 1.2.0 Redux pack. All 160 replay IDs and level versions
match the pinned CE files exactly after applying the NXLV rule that an omitted
`VERSION` means version zero. The corpus contains 1,780 commands. It remains
outside the repository because the attachment does not include a redistribution
licence.

Checked playback initially completed 17/160 levels. Correct CE trigger
rectangles, entrance direction, blocker field geometry and post-movement
blocker handling raised the result to 110/160. CE does not mirror trigger
rectangles with object artwork, horizontally flipped entrances spawn
left-facing lemmings, and blocker force lobes are direction-specific
four-pixel areas that affect workers as well as walkers. Focused renderer and
simulation regressions cover these rules.

Source review then established that CE uses `LEM_IDENTIFIER` or `LEM_INDEX` for
normal playback and treats `LEM_X`, `LEM_Y` and `LEM_DIR` as replay-repair
metadata. CE also continues after a rejected recorded assignment. Matching
those rules, the complete Miner cycle, Basher terrain and steel handling,
action-specific trigger traversal, hoist startup, airborne instant explosions,
the inclusive trap busy cycle and top boundary raised the result to 146/160.
Floater frame-boundary timing, grounded Oh-No Blocker fields and source-exact
Blocker assignment then raised it to 159/160. The remaining `Manic 32` replay
sends its crowd into water before its recorded Nuke can release the final
Blocker; it needs a CE result before it can be accepted or rejected as current
evidence. This archive therefore remains diagnostic rather than a release gate.

An independent full-pack solution set posted in March 2025 adds 160 replays
and 1,895 commands. It was downloaded from attachment 23230 in the
[Lemmings Redux forum topic](https://www.lemmingsforums.net/index.php?topic=4374.msg105852#msg105852),
has SHA-256
`3fee7e54420e7e98f34423ed7b5b42c8ac676881c7b5a9bf05c7903e1aced9b3`, and
remains outside the repository. After Floater frame-boundary timing, grounded
Oh-No Blocker fields, primary-animation trap cooldowns and source-exact Blocker
assignment, the paired runner reaches 160/160 native wins and matches all
160 recorded rescue frames. Both replays whose level versions differ also
complete; all 158 exact-version pairs complete. The source-compatible runner
mirrors CE mass checking: it retains a stale completion frame as diagnostic
evidence and continues to judge the final rescue result. Strict native replay
playback still enforces the recorded frame. Each of the 160 routes also passes
an encoded mid-route playback checkpoint: decoding and continuing produces the
same full playback and simulation state as uninterrupted execution. Final-state
comparison with a live CE oracle and the player-facing pack journey remain
separate gates.

## Repeatable checks

Run the existing source gate from the repository root:

```sh
zsh Scripts/check-1.5-neolemmix.sh
```

When a pinned CE checkout is available, run its development corpus gate:

```sh
zsh Scripts/check-1.5-neolemmix.sh \
  --ce-root /path/to/NeoLemmixCommunityEdition \
  --require-ce-corpus
```

Run a matched level/replay corpus with a complete local styles tree:

```sh
zsh Scripts/run-nxrp-paired-corpus-diagnostics.sh \
  /path/to/levels /path/to/replays /path/to/styles
```
