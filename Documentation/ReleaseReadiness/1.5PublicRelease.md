# macOS 1.5 build 50 public tester release

Prepared 25 September 2026 on Apple silicon with macOS 27.2.

Candidate: `codex/1.5`, version 1.5 build 50.
Release tag: `v1.5-build50`. Release base: `v1.2-build41`.
The packaged notes identify the frozen source commit. This file records the
release checks and is updated after distribution verification.

## Scope

This is a public tester prerelease. It includes the 352-level Classic campaign,
6,020 retained Classic-format fan levels, and 495 soundtrack versions across
210 track identities. Lemmings 2 and Lemmings 3 remain Preview. NeoLemmix
remains Beta or Preview, without full mechanics or reference-replay parity.

The public download is the universal Developer ID app for macOS 12.3 or later.
Game Center stays in the separate development-signed archive for registered Macs.
Hardware and preview-completion gaps remain visible below. They are not closed
by publication of a tester build.

## Preparation evidence

- Music timing: all 495 source hashes, coverage, measured beat positions, loops,
  pickups, compatible bars, fallback rules and packaged timing checks passed.
- Adaptive DJ: real audio loading, rendered pitch and source position, timing
  routing, stale-grid rejection, Classic/L2/L3 journeys, retry stability and
  suspended crossfades passed.
- Music catalogue: identities, provenance, asset coverage and Classic/L2/L3
  packaging checks passed.
- Release readiness: 24 Python tests passed.
- Rescue certificates were regenerated from the current engine. The audit
  covered 562 levels in 574 configurations and packaged 251 exact-condition
  certificates plus 17 best-known rescue targets. These are not completion counts.
- The sequel Settings test now exercises the current preset selector instead
  of calling removed button methods.

## Local app

The universal local app built from `b8cc3df96698f5254349fc2750c84814768ebb23`
passed strict signature verification and a 15-second launch with fresh preferences.
Its first frame appeared in 3.328 seconds, before music. Both `arm64` and
`x86_64` slices are present. Bundled-resource checks ran from `/private/tmp`
and passed. This local app uses an ad-hoc signature and is not a public package.
All 495 packaged audio hashes match the timing catalogue, and the bundled
rescue and hint fingerprints agree.

The complete Apple silicon app integration suite passed after two stale test
assumptions were corrected. The minimap test now uses its current drag bounds,
and the dialog test accepts focus on a control inside the page. A read-only
minimap bounds property supports that test without changing UI behaviour.
The passing run covers controller dispatch, mouse and keyboard input, flat/CRT
presentation, music transitions, hints, saved-run recovery, Hot Seat ownership,
settings, and level-browser actions. Its log is
`.build/release50-app-integration-current.log`.

The local app is about 4.3 GiB with the full soundtrack. Public archive size,
signing and distribution still require validation for the selected source.

## Remaining validation limits

- Physical Intel and minimum supported macOS have not been tested on this Mac.
- Physical-controller and complete VoiceOver journeys remain open.
- Sustained 10× throughput, thermal behaviour and the display hardware matrix
  remain open. Short local rendering checks do not certify those conditions.
- Beat and bar estimates are automated. No complete listening review or manual
  downbeat correction has been performed.
- L2 artwork restoration had a known failure in earlier candidates and has not
  been revalidated here. The current Classic controller dispatch test, including
  retry, rewind and step, passes. Physical-controller testing remains open.
- The sequels do not have complete winning-route and original-engine evidence.
- iPhone and iPad distribution is outside this release.

## Reproduction

```sh
zsh Scripts/run-music-timing-tests.sh
zsh Scripts/run-music-catalogue-tests.sh
zsh Scripts/run-adaptive-dj-playback-tests.sh "$PWD/Sources/Music"
zsh Scripts/check-1.5-neolemmix.sh
python3 -m unittest discover -s Tests/ReleaseReadinessTests
python3 Tools/ReleaseReadiness/audit.py --app --scope classic-1.0
```
