# 1.5 build 43 startup correction

Date: 25 September 2026
Source tag: `v1.5-test-build43`

## Cause

Build 42 used the Game Center snapshot script's `-Onone` default for the app
and shared engine. A five-second sample of that signed app found startup's
main thread repeatedly generating full-window HDR masks during window layout,
even though the effects overlay was empty. The old mask interleaver also
created a temporary two-byte array for every pixel.

The launch sequence called `playMusicForCurrentLevel` while loading the initial
level and returning to the library, before AppKit presented the window. The
old launch smoke check only established that the process stayed alive.

## Change

- Snapshot builds default to `-O` for the app and shared library.
- An empty HDR overlay hides its previous surface and skips mask allocation and
  drawable submission. Active effects retain their rendering path.
- Mask channels are interleaved into one buffer without per-pixel arrays.
- Initial music waits for the full-screen transition and first frame submission.
- The launch smoke gate requires first-frame and music markers, checks their
  ordering, and fails if first-frame submission exceeds five seconds.

The shared HDR overlay change applies to Classic, Lemmings 2 and Lemmings 3.
No simulation, targeting, ownership or handover rules changed.

## Evidence

- `Scripts/run-explosion-hdr-tests.sh` passed idle allocation, active mask,
  clearing, channel equivalence and actual FP16 GPU effect checks.
- The signed app passed the revised 15-second launch smoke check. First frame:
  **3.269 seconds** from delegate construction. Music started afterward.
- A separate sampled launch had these markers: begin 1.233 s, interface 1.415 s,
  audio prepared 2.440 s, content 3.425 s, first frame/music 4.903 s. Profiling
  overhead makes these timings unsuitable for comparison with the unprofiled run.
  No HDR texture-mask generation appeared in that startup sample.
- Proof/replay catalogue validation still passes. No engine source changed.
- The archive is Apple Development signed for registered Apple-silicon Macs,
  with Game Center enabled. It is not notarised. The public feed is unchanged.

## Limits

The marker records a displayed view and flushed Core Animation transaction,
not a hardware scanout measurement. This is local startup evidence, not a
cold-cache benchmark across machines. Existing Preview engine limits remain.
