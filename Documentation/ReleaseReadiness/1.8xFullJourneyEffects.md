# 1.8.x full journey and world-anchored effects

This update restores Oh My! All Lemmings! to 292 curated levels, including fan
levels. It supersedes the 99-level `learning-12` selection. The current manifest
is `learning-13`, with the `redux-calibrated-2` placement policy.

## Journey evidence

The selection contains 100 official and 192 fan levels: 57 Fun, 64 Intermediate,
94 Difficult and 77 Expert. Ninety-four Redux counterparts supply the reference
order; 198 placements are explicit solution estimates. The first seven teaching
levels remain in order. Old built-in journeys migrate while preserving history,
ownership and progress. Custom playlists and newer versions remain unchanged.

Comparisons use actual winning assignments, worker changes, skill combinations,
input timing, spare skills, rescue margin and hatch cadence. Rescue and release
rates do not assign a grade on their own. Estimated beginner additions require
a forgiving route. Initial pixel visibility excludes mostly concealed exits and
traps; explicit unsuitable-level exclusions remain active. The generator fails
if it cannot supply the full 292 levels.

The [current curriculum](../../Artifacts/LearningJourney/README.md) records the
order, source revisions, comparisons and uncertainty. Leave-one-reference-out
median error is 145 placement units, equivalent to 29 Redux positions. This is
substantial uncertainty: replay features cannot establish how easily a new
player discovers a solution. These estimates are not invented human reviews or
proof of a perfectly smooth learning curve. The review queue retains selected
estimates for refinement through ordinary play.

All 1,720 candidates received source-resource and initial visibility audits.
The native replay audit passed 1,705 candidates and rejected 15. The exact
[failures](../../Artifacts/LearningJourney/replay-rejections.json) remain recorded
and cannot enter the selection with those source/replay revisions. Two earlier
292-level attempts failed on stale witnesses; those failures led to the full
pool audit. The final selection passed a fresh native run with exact replay
hashes, accepted commands and winning final states for
[all 292 routes](../../Artifacts/LearningJourney/native-replay-validation.json).
Regeneration now includes this native gate.

## Explosion positioning

Classic/NeoLemmix, Lemmings 2 and Lemmings 3 retain each explosion's world
position and project it through the current camera on every effect frame.
Camera pan, zoom, window resize, CRT curvature and precision lens transforms
therefore move the effect with the terrain. Effect age and exposure do not
restart when the camera changes. Short local flashes use the same projection.

## Validation and limits

- 22 journey tests cover full length, exact witnesses, placement evidence,
  visibility, exclusions, deterministic generation and native proof coverage.
- 36 release-readiness tests pass. Solution fixtures match all 350 hint decks.
- The hint exporter rechecked 352 source solutions before updating the stale
  engine fingerprint inherited from earlier merges; 350 unique decks result.
- HDR tests cover world-coordinate pan, zoom, resize, offscreen travel, lifetime
  and exposure. Existing FP16 GPU readbacks cover HDR/SDR output and expiry.
- The consolidation integration suite passes: profile and session recovery,
  all 292 catalogue entries, saved journey migration, first-lesson starts,
  checked hints, winning replays, L3 story flows and super-speed presentation.
- Automated native tests use the offscreen, muted UI runner. Physical HDR
  display appearance is not certified by headless tests.
- Existing maximum-rescue Trolley certificates remain stale for this engine;
  the bundle correctly leaves those targets unverified.
