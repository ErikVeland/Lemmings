# 2.0 release gate: Lemmings 1–3

**Status: not ready for release.** Route evidence is complete for the three
native campaigns. The signed iOS 2.0 build 12 contains Classic only. It is in
TestFlight beta review and is not a three-game candidate.

## Campaign evidence

| Game | Verified routes | Current release scope |
| --- | --- | --- |
| Classic | 120/120 official levels | Complete |
| Lemmings 2 | 120/120 native routes | Complete. Keep recorded engine-fidelity limits. |

route and survivor evidence is recorded in
[campaign completion](../CampaignCompletion/README.md) and

## Current 2.0 source evidence

- Signed iOS 2.0 build 12 passed export checks and was uploaded to App Store
  Connect. It contains the 120-level Classic campaign only. Apple beta review
  is pending. L2 and L3 were deferred in its metadata. The build is not
  distributed to testers and is not the 2.0 release candidate.
- Lemmings 2 and Lemmings 3 connect to the shared mobile library and session
  flow. Their native renderers, campaign records and checkpoint paths compile
  in the mobile core.
- L3 mobile renders native scenes, terrain edits, tools, animated actors,
  creatures, traps, fireballs and blasts. It now validates and decodes each
  tribe's 320 × 40 panel for wide landscape layouts. Narrow and hinge-split
  layouts use adaptive controls.
- On the exact main commit `c7305724`, the local Xcode 26.6 package build
  passed seven focused tests. The tests covered the import-entry limit,
  controller disconnect policy, all 120 L2 levels, all 90 L3 levels and the
  supported NeoLemmix import. Twelve L2 levels across its tribes and one L3
  level per tribe rendered, ticked and round-tripped checkpoints. The complete
  NeoLemmix import check took 250 seconds. These checks do not prove a full
  campaign playthrough or device acceptance.
- Five more exact-main tests passed. They covered L2 and L3 replay-checkpoint
  restore and campaign completion, plus NeoLemmix import-layout resolution,
  checkpoint restore and one-time completion. Ten shared keyboard-command and
  controller-binding tests also passed.
- The new `LemmingsMobileUITests` real-data test passed with player-owned
  NeoLemmix content. It installed the pack, opened the first, middle and last
  supported levels through `NeoLemmixMobileLibrary`, rendered and ticked each
  session, and round-tripped each checkpoint. The import and session check took
  246 seconds. It does not verify every supported level or source-frame parity.
- PR #13 expands this test to open, render, tick and restore every supported
  NeoLemmix level. The local run skipped it because
  `LEMMINGS_MOBILE_NEOLEMMIX_DATA` is not set. Full-pack session evidence stays
  open.
- The updated player-owned L2 and L3 test passed on the PR branch from main
  commit `b1df3039`. It installed all 120 L2 and all 90 L3 levels, then loaded,
  rendered and ticked every mobile session. It round-tripped checkpoints at
  one level in each L2 tribe and at the start, middle and end of each L3 tribe.
  The L2 test seeds valid 60-survivor results to unlock each level. It does not
  verify natural campaign carry-over or full level playthroughs.
- The main commit `c7305724` passed the macOS workflow, NeoLemmix 1.5 source
  gate and iOS source gate with Xcode 27.2. The iOS source gate passed core
  tests and Debug and Release app builds. Its iPhone layout and lifecycle
  Simulator tests passed on both iPhone and iPad.
- The full `LemmingsMobileCoreTests` run reports 123 passes and eight failures.
  All eight failures depend on the absent `Content/LevelPacks` corpus. The
  Classic official-level render/tick test passes all 352 levels.
- The onboarding-aware import-route UI test passed on both iPhone and iPad in
  pull request checks for commit `4d0c0a7f`. The main iPhone layout and
  lifecycle jobs also passed for `c7305724`.
- Xcode 26.6 is installed on this host. Its iOS 26.5 SDK lacks the iOS 27
  APIs used by the full app, and CoreSimulatorService cannot provide a local

- Real-data panel artwork comparison and full campaign playthroughs remain
  unverified on this host.

## Release blockers

1. Verify full L1, L2 and L3 playthroughs, artwork, controls, checkpoints,
   retry and continue flows against approved game data. Current L2 and L3
   tests load, render and tick every level session, but do not prove natural
   campaign carry-over or full runs from start to finish.
2. Complete physical iPhone, iPad and iPhone Duo acceptance. Check touch,
   accessibility, rotation, resize, interruption, recovery and performance.
3. Close the required shared input, audio and controller journeys. Record each
   engine limit in the evidence.
4. Freeze the three-game source and approved content. Build and sign a new
   three-game candidate. Verify offline startup, privacy metadata, icons,
   screenshots, update and save migration. Then complete TestFlight and App
   Store checks for that candidate.
5. Close the separate supported NeoLemmix CE gate required by the 2.0 roadmap.

The release register keeps the iOS content, device acceptance and distribution
gates open. Do not publish or label build 12 as the full 2.0 release. Update
this record with the exact release commit and candidate evidence when each
blocker passes.
