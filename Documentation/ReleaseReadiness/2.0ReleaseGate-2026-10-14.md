# 2.0 release gate: Lemmings 1–3

**Status: not ready for release.** The route evidence is complete for the three
native campaigns. The iOS 2.0 candidate and device acceptance are not complete.
The installed build 8 is a Classic beta, not a three-game release candidate.

## Campaign evidence

| Game | Verified routes | Current release scope |
| --- | --- | --- |
| Classic | 120/120 official levels | Complete |
| Lemmings 2 | 120/120 native routes | Complete. Keep recorded engine-fidelity limits. |
| Lemmings 3 | 90/90 standalone routes and 90/90 linked campaign results. All three tribes finish with 50 survivors. | Beta until engine fidelity and package gates pass. |

The strict L3 proof replays 326 carried-population fixtures twice. The current
route and survivor evidence is recorded in
[campaign completion](../CampaignCompletion/README.md) and
[sequel verification](1.8SequelVerification.md). Route completion does not prove
source-engine parity or mobile acceptance.

## Current 2.0 source evidence

- Classic has a signed, installed iPad beta at version 2.0 build 8. Its
  three-game release, manual gameplay acceptance and TestFlight upload remain
  open.
- Lemmings 2 and Lemmings 3 connect to the shared mobile library and session
  flow. Their native renderers, campaign records and checkpoint paths compile
  in the mobile core.
- L3 mobile renders native scenes, terrain edits, tools, animated actors,
  creatures, traps, fireballs and blasts. It now validates and decodes each
  tribe's 320 × 40 panel for wide landscape layouts. Narrow and hinge-split
  layouts use adaptive controls.
- Player-owned content passed local source checks without adding game files to
  the repository. L2 installed as a 120-level campaign; 12 representative
  levels across the tribes rendered, ticked and round-tripped checkpoints. L3
  installed as a 90-level campaign; one representative level for each tribe
  rendered, ticked and round-tripped checkpoints. NeoLemmix import validated
  every level with complete styles and retained levels whose imported styles
  are available; that full import check took 242 seconds. These checks do not
  prove device performance, visual parity or full campaign playthroughs.
- Thirteen focused layout and L3 renderer tests pass on the Mac test host.
  `LemmingsMobileCore` builds for the arm64 iOS 16 Simulator target with the
  installed Xcode 26.5 SDK.
- The full `LemmingsMobileCoreTests` run reports 123 passes and eight failures.
  All eight failures depend on the absent `Content/LevelPacks` corpus. The
  Classic official-level render/tick test passes all 352 levels.
- A full `LemmingsMobileUI` build against iOS 26.5 reaches the iOS 27.1
  reserved-region calls, then fails because this SDK does not define those
  UIKit APIs. The Xcode app target and Simulator flow remain unverified.
- `Scripts/check-1.3-mobile.sh --require-sdk` passes its project and source
  checks, then stops because CoreSimulatorService cannot report installed
  runtimes. A direct Xcode app build also fails package resolution for the
  local `LemmingsMobileUI` product on this host.
- Real-data panel artwork comparison and full campaign playthroughs remain
  unverified on this host.

## Release blockers

1. Build the full app with the release Xcode 27 toolchain. Pass Debug, Release
   Simulator and unsigned device builds on the exact source commit.
2. Verify every campaign, renderer, control, checkpoint, retry and continue
   flow against the source artwork and real data. The local import checks cover
   campaign counts and representative sessions only.
3. Complete iPhone, iPad and iPhone Duo UI acceptance. Check touch targets,
   accessibility, rotation, resize, interruption, recovery and performance.
4. Close the required shared input, audio and controller journeys. Record each
   engine limit in the evidence.
5. Freeze the three-game source and approved content. Build and sign a new
   three-game candidate. Verify offline startup, privacy metadata, icons,
   screenshots, update and save migration, then complete TestFlight and App
   Store checks.
6. Close the separate supported NeoLemmix CE gate required by the 2.0 roadmap.

The release register keeps the iOS content, device acceptance and distribution
gates open. Do not publish or label the current Classic beta as the full 2.0
release. Update this record with the exact release commit and candidate evidence
when each blocker passes.
