## Release gates

`Scripts/build-and-notarise.sh` built four targets. All gates passed:

- Rescue proofs and level hints match the engine: 251 proofs and 17 records.
- The app integration tests passed on the full-soundtrack build.
- Apple notarised the full, slim and Monterey targets. Gatekeeper accepted all three.
- Each target passed the launch smoke test with an empty home.
- The full build bundles 495 versions and offers no library for download. The slim
  build bundles 54 versions and includes no library.
- The update archive is below the 2 GiB GitHub asset limit.

Both public apps are universal (x86_64 and arm64), version 1.6 build 51, with a
macOS 12.3 minimum. Neither contains `AnonymousTelemetryURL`, so play counts stay
on the Mac.

Before packaging, every suite passed on the release commit: app integration,
music UI, music library, adaptive DJ playback, Trolley, game flow, Lemmings 2 and
Lemmings 3 runtimes, precision zoom, failure mood, playfield drawing, the 25 beta
regression suites, release readiness, and the telemetry client and server tests.

## Actual upgrade

The test started from the public 1.5.0 archive. Sparkle 2.7.3's command-line
driver updated it from the live feed and reported `Installation Finished`.

The installed app changed from 1.5 build 50 to 1.6 build 51. It kept the full
soundtrack of 495 versions, so the player downloads nothing again. It passed
strict signature checks, stapled-ticket validation and Gatekeeper
(`Notarized Developer ID`). Its binary was identical to the binary in the release
package. A second probe reported no newer update.

## Packaging note

The first package run stopped at the slim submission. The screen locked during
the run, and background processes cannot read the data-protection keychain item
for the `lemmings-beta` profile while the session is locked. The second run kept
the Mac awake with `caffeinate`. Keep the session unlocked during release runs.

## Limits

This is distribution and startup evidence. Physical Intel and minimum-macOS
testing remain unverified. The Game Center target is development-signed for
registered Macs and is not published.
