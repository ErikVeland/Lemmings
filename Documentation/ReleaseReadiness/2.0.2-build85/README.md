## Validation

[Final local validation](final-audit.json) records 66 passing check groups. [CI](ci-final.json) passes shared regressions, a universal Release executable and distribution tooling. [Candidate inputs](candidate-inputs.json) verify seven universal binaries, macOS 12.3 metadata, current hints, proofs, journey data and localisation. Production Swift sources match the compiled candidate. Only regression-test repairs and diagnostics changed after compilation.

The raw audit ran out of disk space before it could save its final report. Its console, input manifest and logs are retained. The sequel and records jobs could not run with the full disk. Both have passing reruns using the candidate libraries. Removing eight obsolete Sparkle extraction caches recovered about 20 GB. Release apps, archives, source and evidence were retained.

The first performance run filled the replay encoder queue while compilation and archive work were active. The isolated rerun passes flat, monitor and television scenarios, including exact encoded frame counts. This is a short local measurement, not sustained hardware certification.

The first release-note scope lacked its capture directory. Its clean-build fixture is repaired. Short notes retain reachable scrolling and Continue targets. Fresh renders and the rerun pass. Raw failures remain separate from passing reruns.

Two earlier CI runs failed the cloud-conflict case. Thirty direct repetitions passed locally. Explicit archive-boundary and sync-state diagnostics were added. Final CI passes. Physical cross-device synchronisation remains unverified, and no cloud-reliability closure is claimed.

The native checks cover Classic, L2 and L3 ghost timelines, session isolation, owner exclusion, rewind, input surfaces and movie-frame inclusion. The full replay-movie suite also passes. Representative ghost, result, reward and welcome renders were inspected. All automated native checks use the offscreen runner with muted audio. Foreground focus checks and the signed full-screen launch smoke were not run because the owner requires background testing. Physical controllers, VoiceOver, audible listening, Intel/minimum-OS hardware, composited CRT/HDR, language review and device acceptance retain their gaps.
