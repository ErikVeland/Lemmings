# 1.8.3 build 72 distribution verification

Release: [Ultimate Lemmings 1.8.3](https://github.com/ErikVeland/Lemmings/releases/tag/v1.8.3).
Frozen source: `0e49151f13fee037aa4cbc8050086a758cdbbb40`.
Release base: v1.8.1. Changes include the local 1.8.2 test builds.

This release adds optional hosted worldwide records and replay sharing, local
speed records, the refined 294-level journey, and refreshed rescue targets.
NeoLemmix remains Beta. Lemmings 2 and Lemmings 3 remain Preview.

The full update and slim fresh-install download contain universal arm64/x86_64
code for macOS 12.3 or later. The full update retains bundled music; the slim
download includes essential music and supports optional soundtrack libraries.

## Validation

The minor regression audit passed 48 checks with zero source drift. The separate
fresh packaged-resource integration run passed journey starts, unopened fan-pack
continuation, saved-run recovery and player ownership across Classic, L2 and L3,
NeoLemmix progression and Escape handling, solution audio, and scrollable release
notes at three sizes. Release notes were visually checked at the scroll endpoints.

Replay movie checks passed exact frame clocks, directional ghosts, controls and
encoded audio. Six hosted-client tests, 11 backend tests and 36 release-tool tests
passed. The live hosted service passed its smoke test and removed its test player.
The service received the same refreshed rescue catalogue bundled with the app.

Native rescue verification covers 562 levels and 574 configurations. The catalogue
retains 251 maximum proofs and 261 best-known rescue records. All 350 hint routes
passed. L3 verification retains 74 distinct wins with 16 missing; the three open
continuous campaign chains remain recorded in the L3 completion log.

## Distribution

Both downloads passed Apple notarisation, ticket stapling, strict code signatures,
ZIP integrity and quarantined Gatekeeper assessment. The full archive's Ed25519
signature was checked against the public key embedded in the shipping app. All
previous update-feed enclosures were retained unchanged.

Published 8 October 2026. Both remote archive hashes and sizes match the local
notarised ZIPs. Public download responses, the frozen source tag, and the main
branch and public raw Sparkle feeds passed verification.

## Limits

All native UI checks stayed offscreen and test audio stayed muted. Encoded audio
was checked without playback. No foreground shipping-app launch, audible listening,
physical Intel/minimum-macOS checks, installed Sparkle upgrade, sustained performance
benchmark or complete sequel campaign certification was performed. The broad app,
sequel-view and arcade audit groups were not run; focused integration evidence is
recorded separately. These limits do not change the Beta and Preview labels.
