# 2.2.1 build 98 release record

Release requested on 23 October 2026 after the owner confirmed that the
installed Mac desktop clock widget works. The release includes widget startup,
full-size artwork and desktop appearance fixes, plus shared mobile pause and
resume timing fixes. See the [release notes](../../ReleaseNotes-2.2.1-build98.md).

The candidate uses Mac build 98, iOS build 21 and tvOS build 11. All archives
must come from one frozen source commit. Publication and verification receipts
will be added after the signed packages pass their checks.

Automated checks stay offscreen with muted audio. Foreground launch and updater
relaunch are outside the authorised test mode. Physical-device, cloud,
minimum-OS hardware and full-corpus acceptance retain the limits in the
[previous release record](../2.2-build97/README.md).
