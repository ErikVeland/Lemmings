# Ultimate Lemmings — beta 32

Version 0.1, build 32. Universal Mac app for Intel and Apple silicon, macOS 12.3 or later.
Full soundtracks are included.

Beta 32 comes as one notarised archive, **UltimateLemmings-0.1-beta32.zip**. It runs on any
supported Mac and uses local records. There is no Game Center build of beta 32. Game Center
testers can keep using beta 31.

## New in beta 32

- The app now runs on macOS 12.3 Monterey and later. Earlier betas needed macOS 13. This
  includes Intel Macs that stop at Monterey, such as the 2015 MacBook Pro.
- Every Classic panel button now sits on the rock background from the original Amiga panel,
  inside the stone bevel. This includes the skills, the rate buttons, Pause, Nuke, Undo Nuke
  and the speed box.
- The speed box shows the speed the game is running at now, for example 1X after you return
  to normal speed. The label is centred at every window size, and the separate fast-forward
  icon is gone. This also applies to Lemmings 2 and Lemmings 3.
- The rate buttons, the speed label and the skill shortcut letters use the game font.

## Install

1. Quit any other copy of Ultimate Lemmings.
2. Unpack the ZIP and move Ultimate Lemmings.app to Applications.
3. Open the app.

## What to test

- On macOS 12, and on Intel Macs in particular: open the app, start a Classic level, and play
  for a few minutes. Check the menus, sound, music, fast-forward and the CRT display option.
- Check the Classic panel at your window size: the rock background, the stone bevels and the
  readable labels.
- Speed up with the speed box or the arrows, then return to normal speed. The box must show
  the current speed each time.

Report the build number, your Mac model, your macOS version, the level and the steps when a
test fails.

## Known limits

- macOS 12 has not been tested on a real Mac before this beta. On Intel Macs, the app is
  built without one Swift compatibility library for macOS 12, because the build tools do not
  include it for Intel. Report any crash with its crash report.
- HDR effects need an HDR display. Other Macs show the standard look.
- Classic has verified wins for 238 of 292 official levels. Lemmings 2 remains a preview with
  wins for 64 of 120 levels and no complete ten-level tribe run. Lemmings 3 remains a preview
  with wins for 17 of 90 levels.
