# Ultimate Lemmings 1.2 (build 40)

Build: 40

Fix automatic updates not starting until the first manual update check. Sparkle
now starts when the app launches. Existing build 39 installations can select
**Ultimate Lemmings → Check for Updates…** to download and install this build.

Universal app for Intel and Apple silicon, macOS 12.3 or later. The public app
and all bundled Sparkle components are Developer ID signed and Apple notarised.
No device registration is required.

For a new installation, expand the ZIP, move Ultimate Lemmings.app to
Applications, then open it.

Lemmings 2 and Lemmings 3 remain previews. Known artwork-toggle and controller
sequence issues remain. Physical Intel and minimum-macOS testing is unverified.
The device-restricted Game Center variant is not included.
