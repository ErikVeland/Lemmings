# Ultimate Lemmings 1.7.2 — Keyboard Controls and Fan Levels

Build: 55
Release base: v1.7.1

## Keyboard controls

- − and + change the release rate by one step.
- Double-tap − or + to set the release rate to the minimum or the maximum.
- Press N to nuke. Press N again to undo the nuke while undo is still possible.
- Outside play, N in Classic still opens the next level.
- The controls help (?) shows the new keys.

## Classic fan levels

- 30 more Classic fan levels can now be completed. The DOS rules ignored the
  exits on these levels. The exits now work, as they do in the fan editors.
- The number of verified Classic fan levels is now 2,095.

## Oh My! All Lemmings!

- The journey has a smoother lesson order. Each step now keeps the next level
  close in difficulty to the level before it.
- The journey has more verified solutions.

## NeoLemmix fixes

- A Disarmer now disables a trap when it starts work. Lemmings that follow can
  walk past the trap safely.
- Builders, Platformers and Stackers continue their work correctly after a
  teleporter.
- Stackers now start their stack at the correct height.
- Teleporters move the lemming on the correct animation frame.
