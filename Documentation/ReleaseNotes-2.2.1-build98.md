# Ultimate Lemmings 2.2.1

Build: 98
Release commit: 285dbabd432ecdf3fc3414e087a92058b7018f0b
Release base: v2.2

## A clock at home

Mac Desk Clock widgets now start correctly after installation. Clock artwork
fills each widget size. Full-colour and tinted desktop appearances keep the
clock visible; monochrome appearances show its pixel silhouette.

Widgets update through the system timeline. Open Desk Clock in the app for
continuous animation.

## Pause when you press

The mobile touch HUD pauses on touch-down. Releasing the same press keeps the
game paused. Resume presents the frozen playfield before the next game tick
and discards time spent paused. These timing fixes apply to Classic, The Tribes
and Chronicles, including fast play. Hot Seat still waits for Ready.

## Platforms and scope

Mac build 98 supports Apple silicon and Intel on macOS 12.3 or later.
iPhone, iPad and Duo use build 21 on iOS 16 or later. Apple TV uses build 11.
The existing TestFlight groups and AltStore Classic source continue.

Classic and The Tribes remain Complete. Chronicles and NeoLemmix remain Beta
with their documented limits. Mobile Journey still plays Classic levels.
Physical-device acceptance retains its recorded limits. Apple processing and
Beta Review determine external TestFlight availability.
