# Ultimate Lemmings 1.9.3 — Signed incremental updates

Build: 77
Release base: v1.9.1

This candidate restores signed Sparkle delta updates. Supported installations can
download changed app files instead of the full update archive. Sparkle uses the
full archive when a matching delta is not available or the delta fails.

The app content matches 1.9.1. Lemmings 2: The Tribes remains Complete with all
120 routes verified. Lemmings 3: Chronicles remains Beta with 74 of 90 routes
verified. NeoLemmix remains Beta. The 1.9.1 targeting, display and nuke fixes
remain included.

## Compatibility and validation scope

Universal macOS app for Apple silicon and Intel, macOS 12.3 or later. This draft
does not record a new app build, package, installation or update test. The
release process must verify the frozen build and its signed delta before release.
