# Ultimate Lemmix logo

`ultimate-lemmix.png` is the transparent, app-owned logo for Ultimate Lemmix.
It adapts the current Ultimate Lemmings wordmark and gold Ultimate badge.
The characters use the Lix appearance: blonde hair, red shirts and teal trousers.

The image was generated on 18 November 2026 from the existing startup logo and
the pinned Lix sprite preview. Keep this logo separate from imported game art.
The Ultimate Lemmings release retains its own logo.
