# Open Starter data

These three puzzles are authored for this project. The files contain native
Classic level records, independent terrain masks, and hatch and exit metadata.
They contain no payload from a commercial game. The separate Lix artwork
supplies the visible terrain, objects and characters. The neutral terrain
pixels and transparent source objects carry geometry for the existing loader.

Copy the three DAT files and `starter-manifest.json` to
`Ports/ultimate_lemmix_starter` in the app resources. Load that folder with
`ClassicDataSet.detect(directory:)` and `ClassicGroundSet.load(style:from:)`.
The loader exposes three levels in physical order, under the `All` rank.
The manifest identifies this authored starter; the `LEVEL` prefix alone does
not identify it. This data does not need `MAIN.DAT` or destruction masks.

Regenerate with `python3 Tools/AlternativeAssets/prepare_open_starter.py`.
Use its `--check` option to compare the generated bytes and manifest.
