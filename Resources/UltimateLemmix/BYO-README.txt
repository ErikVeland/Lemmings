Ultimate Lemmix: player-owned assets

This helper contains only this guide and a JSON import contract.
It contains no game assets, executable code or game-file downloads.

To restore the original presentation from your existing preservation app:
1. Open Import owned games.
2. Choose Restore original assets.
3. Choose your Ultimate Lemmings.app or a prepared asset folder.

The importer reads the selected files. It does not run the supplied app or the
original game engines. It stages and validates a copy before activation.
Original artwork, fonts, sounds and music remain outside the installed app.
The source files and your previous import remain in place.

The Classic, Lemmings 2 and Lemmings 3 game-folder controls import the data
inside those folders. A raw DOS folder does not also supply Macintosh or
Amiga presentation, archival music or the full preservation asset collection.

The app keeps its current trusted metadata and proof identities. Your own
files do not grant redistribution permission. No helper action downloads them.
